# Free handling artwork

The 14 SVG source files are downloaded from Wikimedia Commons. See `sources.json` for the author, original file page, per-file license and original SHA-256. All are CC0-1.0 or public-domain artwork; redistribution, modification and commercial use are allowed. No graphics are hotlinked at runtime.

CC0 deed: https://creativecommons.org/publicdomain/zero/1.0/

`stackLimit`, `stackHeight` and `noStack` are documented compositions of the imported package silhouette, arrows and prohibition cross. They are application illustrations, not representations of ISO certification. Legacy layer counts keep the existing meaning (total boxes including the bottom box).

Source gray registration guides are excluded from output. Curves, compound paths, fill rules, stroke caps and transforms are preserved. Numeric parameter labels use outlined DejaVu Sans Bold glyphs; see DejaVu-LICENSE.txt. The author notices accompany these outlines in the production assets.
