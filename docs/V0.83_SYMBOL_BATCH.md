# V0.83 标识组合排版

在独立唛头的「标识」或纸箱设计的「唛头」中，打开「标识组合排版」。纸箱设计先选择目标面；独立唛头使用当前正唛或侧唛。选用易碎品、重箱搬运、开箱提示组合，或者搜索并勾选最多 8 个标识。预览会按勾选顺序显示物理尺寸，允许设置边长、间距和每行数量。

插入时在目标面的安全区内寻找一块连续区域，避开已有可见图文的外包络。对于凹形刀版，组合矩形须完整落在面内。若未找到位置，缩小组合、移动已有对象或换面后再试；不会缩放用户设定的尺寸，也不会只插入其中一部分。

每个标识作为普通矢量对象保存，仍可单独调整。组合插入是一条撤销记录，支持原有 SVG／PDF／PNG 输出和项目 ZIP。堆码层数、高度、重量与温度范围需要单独添加并填写对应数值。

验证入口：`npm run test:v83` 检查尺寸、遮挡、凹槽、失败不写入、矢量导出、3D 贴图指令和正侧唛项目恢复。GitHub Actions 的 Carton Symbols and Batch Placement 检查桌面及手机界面，并复核原有下载。
