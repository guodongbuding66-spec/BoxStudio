## V0.31 regression coverage

### Production PDF digital decode

The tests generate the actual V0.27 Production PDF bytes, isolate the code regions from PDF vector rectangles, rasterize those regions in memory, decode them, and compare the decoded result with the configured source.

Verified barcode routes:

- Code 39;
- EAN-13;
- UPC-A;
- ITF-14;
- GS1-128 / Code128-B with FNC1 and checksum.

Verified QR route:

- current BoxStudio QR encoder scope: Version 1–4, ECL L, byte mode.

The GS1-128 verifier uses per-symbol run-pattern fitting against the canonical Code128 symbol table to avoid raster rounding errors from simple minimum-run quantization.

#### Final-artifact negative proof

The hardening regression modifies one filled barcode bar directly in the **generated Production PDF bytes** (`re f` -> same-length `re S`) without changing source variables. The digital decoder must then reject the artifact.

Result: **PASS — corruption detected and Production acceptance fails.**

This closes the ambiguity between “encoder/source validation” and “verification of the final Production PDF artifact.”

### Preview / PDF geometry acceptance

The regression verifies:

- page MediaBox physical dimensions;
- core mark rectangles;
- normal text anchors;
- technical outlined-text glyph key rectangles read back from final PDF paint geometry;
- artwork lines;
- CUT / CREASE / PERF / GLUE key lines;
- tolerance `<= 0.2 mm`;
- stale-artwork detection by comparing changed Preview geometry against an older PDF artifact;
- unsupported 90 / 180 / 270 degree element rotation fails closed.

TTF outline geometry is not silently skipped: until independent TTF glyph-path readback is available, that mode is a blocking geometry-verification failure.

## P0 closure statement

The repository-internal digital/geometry requirements are considered closed when all of the following remain true:

1. the final Production PDF artifact is the decode source;
2. deliberate final-byte barcode damage is detected;
3. Barcode and QR source values round-trip successfully for supported symbologies;
4. Preview/PDF key-point geometry is independently measured with default tolerance `<= 0.2 mm`;
5. technical outlined text is included in final-PDF geometry readback;
6. unsupported rotation / unverified TTF-outline geometry fails closed;
7. Required Checks cannot be disabled into a warning-only path;
8. CI executes both positive and negative acceptance cases.
