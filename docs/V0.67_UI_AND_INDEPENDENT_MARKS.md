# V0.67 界面与独立唛头

日期：2026-10-08。基于已授权同步的 V0.66（914c523ff9af6441fa6dd246ade2361fdf81cf5f），沿用免费、无需登录的设计功能。

## 设计依据与变化

参考 ui-skills.com 的 interface-design 与 better-ui 指南，明确包装设计师与外贸人员的工作路径，以毫米画布作为界面中心。设计意图、颜色、间距、字体、表面和动效记录于 `.interface-design/system.md`。

- 顶部统一为品牌、纸盒 / 唛头模式切换、项目、保存、导出；复杂度与客户印刷配置收进设置菜单。
- 纸盒工作台使用工具栏、左侧素材与面板设置、中央展开图、右侧检查器。阶段导航缩为一行，更多编辑工具保留在菜单中。
- 唛头组件采用一致的矢量图标与分组；数据、对象属性和批量数据通过检查器切换。
- 独立唛头工作台可以直接进入。组件 / 模板 / 图层放左侧，物理尺寸、适合窗口、撤销、复制、删除围绕画布排列，右侧编辑运输数据和对象。
- 按钮使用 120ms 颜色反馈与按压 .96；窗口使用 180ms 淡入与 6px 位移；系统减少动态效果时关闭运动。没有新增观察器，界面仍使用已有共享调度器。
- 手机上素材通过原生 dialog 打开，检查器排列在画布下方，保留横向可用画布；关闭素材窗口后恢复素材节点。

## 独立文档与实际功能

独立项目使用 `boxstudio-standalone-mark` schema 和单独存储键，不修改纸盒的结构、对象、变量或历史。默认是 320 × 220 mm 单页画布，可改宽 40–1500 mm、高 30–1500 mm。支持标准运输、外贸信息与空白模板。

组件包含运输信息、变量文字、Code 39 / EAN-13 / UPC-A / ITF-14 / GS1-128 + QR 组合、向上 / 易碎 / 防潮符号，还可添加文字、矩形和嵌入图片。支持拖动、毫米属性、复制、删除、键盘微移、独立撤销 / 重做、图层排序与显隐。

CRN 绑定可同时出现在多个位置。多包裹提示仅在总包裹数大于 1 时显示。组合条码宽高保持 3.125 : 1，最小 100 × 32 mm，避免二维码、条码与留白超出组合。模板条码和多包裹提示互不覆盖。

项目支持命名、保存、副本、JSON 导入导出与本地恢复。无效 schema、重复编号、错误数值、旋转、图片来源或组合比例会拒绝导入；导入和模板切换之前保存当前项目。保存失败时保留上一份文档，显示可操作的错误信息。

PDF 使用实际毫米 MediaBox，输出单页唛头，不带纸盒刀线。SVG 为矢量输出；PNG 以 96 / 150 / 300 DPI 计算实际像素尺寸，限制 4000 万像素；JSON 保留可再次编辑的项目。PDF 与 SVG 使用同源运输符号路径。中文 PDF 需要本次会话加载支持对应字符的 TTF，缺失字体或字符时阻止输出；SVG / PNG 可直接使用中文。

## 范围

本次聚焦界面和独立唛头设计。已实现盒型仍为 8 个；独立唛头暂不提供 Excel 批量导出，批量功能保留在纸盒唛头检查器。项目快照在当前浏览器，线上账号与多人云同步尚未部署。PDF 是生产文件输出，未声明 PDF/X 认证或替代工厂实物打样。V0.66 参考站点功能差距记录仍适用。
