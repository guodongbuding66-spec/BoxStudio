# BoxStudio V0.17 Development & Test Report

## Scope

V0.17 turns the V0.16 Panel Artwork Texture Atlas into a real folded 3D artwork proof path.

Primary goals:

1. project panel-local artwork onto folded panel geometry;
2. support rectangular and polygon panels through UV triangulation;
3. expose fold-seam UV diagnostics instead of hiding uncertain mappings;
4. keep the preview independent of external 3D libraries so it still works when Three.js is not bundled.

V0.17 does **not** claim print-RIP color accuracy, substrate distortion simulation, ink trapping simulation, complete Illustrator appearance fidelity, or certified soft proofing.

## 1. Folded Artwork Texture Proof

### Added

- `src/threeArtworkProof.js`
- `src/v17Ui.js`
- `src/v17Ui.css`

The renderer consumes the same panel artwork plans created by `src/panelArtwork.js`.

Supported texture content therefore includes the currently normalized artwork commands for:

- variable text;
- conditional package notice;
- shipping icons;
- line / rectangle artwork;
- Barcode + QR;
- imported SVG vector marks.

Each panel is rasterized into its own panel-local artwork texture, then projected onto the folded 3D panel surface.

The proof renderer supports:

- Fold 0–100%;
- pointer drag orbit;
- mouse-wheel zoom;
- texture rebuild;
- reset view;
- depth sorting of folded panels;
- visible panel boundary wireframe.

The renderer is implemented with Canvas 2D triangle texture mapping. It does not depend on a bundled Three.js runtime.

## 2. Polygon UV Triangulation

`threeArtworkProof.js` adds ear-clipping triangulation for simple polygon panels.

For each panel:

1. panel geometry is normalized to a polygon;
2. panel-local UV coordinates are generated from the panel bounding domain;
3. the polygon is triangulated;
4. each source texture triangle is affine-mapped into the projected screen triangle.

Rectangular panels produce two triangles.

Simple concave polygon panels are handled through ear clipping. If triangulation cannot resolve a malformed/self-intersecting polygon, the renderer uses an explicit fan-triangulation fallback and surfaces that fallback in the V0.17 UI.

This fallback is a preview safeguard, not a claim that malformed production geometry is valid.

## 3. Fold Seam UV Diagnostics

V0.17 adds a fold seam report for every Fold Graph edge.

The report checks whether the hinge endpoints map into the UV domain of both connected panels.

The UI shows:

- source panel;
- destination panel;
- hinge label;
- hinge length;
- source-panel UV endpoints;
- destination-panel UV endpoints;
- whether the fold uses a fallback hinge;
- mapped / warning status.

This verifies that the texture coordinate system is structurally usable across the fold graph.

It does **not** claim automatic continuation of one image across two independent panel artworks. Cross-panel artwork continuity remains a separate production-design feature.

## 4. Storage Migration

Browser project state key:

```text
boxstudio-mvp-v17
```

V0.16 and earlier keys remain migration sources.

No existing IndexedDB artifact schema is changed in this release.

## 5. Automated Regression Coverage

New `tests/v17.mjs` covers:

- concave polygon ear-clipping triangulation;
- rectangle UV generation;
- panel UV bounds;
- default RSC fold hinge UV mapping;
- folded artwork proof model creation;
- artwork command presence;
- UV triangle counts;
- Fold 0% versus Fold 100% transform changes.

CI also continues to run all earlier regression suites from smoke through V0.16.

## Known Boundaries / Next Work

Still not completed in V0.17:

- color-managed 3D soft proofing;
- ICC-aware display conversion in the 3D proof;
- paper/board thickness and bend-radius deformation;
- physical print stretch around folds;
- automatic cross-panel image continuation;
- complete SVG fill / gradient / clip / mask / CSS fidelity;
- hosted BoxStudio backend and authenticated collaboration;
- CRDT/OT real-time multi-user editing;
- factory compensation profiles without verified production data.
