# V0.59 Reference Deep Dive — Pacdora + Packform

## Scope
This pass deliberately returns BoxStudio to the original product goal: a free-for-everyone online paper-box design tool with a low-friction path from structure selection to dimensions, dieline/artwork, 3D, shipping marks and export.

References:
- Pacdora custom dieline / dieline library: https://www.pacdora.cn/dielines-detail/custom-dimensions-flip-top-boxes-mailer-dieline-150010?key=99&id=47319649
- Pacdora public dieline/template pages and indexed editor screenshots
- Packform: https://ds.mxder.com/
- Packform public pages: `/free-box-design/`, `/box-dieline-generator/`, `/box-template-generator/`

A live step-by-step browser automation session was attempted for the Pacdora detail page, but the connected metered browser wallet had insufficient balance. Therefore this document separates public/current observations from inferred interaction patterns and does not claim every authenticated modal was exercised.

## Directly observed / publicly documented patterns

### Pacdora
1. The primary journey is compressed: choose a template → customize dimensions/material/thickness → inspect the dieline and 3D → download.
2. Template detail/editor screenshots consistently show a large neutral dieline workspace and a compact 3D/output area rather than a dashboard-first engineering flow.
3. Inner / manufacturing / outer dimensions are first-class size modes.
4. Bleed, trim/cut and crease are visually distinct on the dieline.
5. Public pages expose PDF / AI / DXF and 3D/mockup outputs as prominent end actions.
6. 3D is used as immediate design feedback, not a separate late-stage system.
7. The public product positions advanced packaging structure capabilities behind a simple initial workflow.

### Packform
1. Structure dimensions, editable dieline, artwork and 3D live in one project.
2. The 2D workspace uses millimeter coordinates and allows text/image/color editing.
3. Advanced dieline editing includes line/arc/Bezier/free curves and node operations.
4. Geometry changes rebuild the linked 3D panels.
5. SVG output is part of the normal workflow.
6. The public pages explicitly describe image upload, text placement, panel colors and cross-panel layout checks.
7. The product is positioned as usable in desktop and mobile browsers without installing CAD software.

## BoxStudio gap analysis after V0.58

### Closed or substantially closed
- real parametric structure engines
- verified template library
- inner/manufacturing/external dimension conversion
- 2D dieline editing
- advanced curve/CAD tools
- linked 3D fold graph
- shipping-mark variables, barcode/QR and Excel/CSV batch workflows
- production PDF/SVG/DXF/PNG export
- mobile browser layout
- free core workflow with no login/paywall/trial gate

### Still weaker than the references
1. Template selection still opens a configuration overlay rather than feeling like a dedicated dieline-detail workbench.
2. The editor exposes too much accumulated engineering complexity to first-time users.
3. The base artwork Image tool is still not a finished first-class workflow; this remains a P0 gap versus both references.
4. Panel background/color editing is not yet presented as a simple packaging-design action.
5. The basic design flow and the professional CAD/Preflight flow need stronger progressive disclosure.

## V0.59 product decisions

### 1. Dedicated template-detail workbench
When a verified template is configured, the overlay becomes a full-height three-column workbench:
- left: dimensions, material, thickness, presets
- center: large dieline preview with print-line legend
- right: inside/manufacturing/outside summaries, real BoxStudio export formats and 3D handoff

No fake AI exporter is introduced. BoxStudio continues to advertise only the formats it actually produces: PDF, SVG, DXF and PNG. AI interoperability remains through standards-compatible vector/PDF workflows rather than a falsely labeled `.ai` file.

### 2. Simple vs Professional mode
Default **Simple** mode presents the core journey:
`Structure → Design → 3D → Marks → Export`

**Professional** mode restores the accumulated engineering controls such as explicit Preflight and advanced production/factory panels. Existing capability is retained; it is not deleted.

### 3. Shipping marks remain first-class
Marks keeps target-panel selection, preset components, variables, barcode/QR, Excel/CSV batch data and linked 3D validation in the same editor.

### 4. Next P0 after V0.59
Real artwork image upload / placement / persistence / 3D texture / export must be completed before the product can be considered feature-parity oriented with Pacdora/Packform. V0.59 deliberately does not hide this remaining gap.
