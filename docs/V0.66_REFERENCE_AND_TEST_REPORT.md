# V0.66 纸盒设计与唛头编辑验收

日期：2026-10-08。开发基于 V0.65 的 `f4d5a2ea794aca27ff25d21a9715176cbbed9590`，延续免费、无需登录的纸盒设计主流程。

## 本次参考核对

再次操作并查看以下网站的真实页面，而不是仅参考首页图片：

- [Pacdora 飞机盒 150010](https://www.pacdora.cn/dielines-detail/custom-dimensions-flip-top-boxes-mailer-dieline-150010?key=99&id=47319649)：观察盒型搜索、资源库、折叠控件和 AI/PDF/DXF/3D 下载入口。该浏览器中的模型持续显示构建中，因此没有把完整模型交互或下载执行计入验证。
- [Packform](https://ds.mxder.com/)：操作参数、2D 对象、面板颜色、单面/多面视图、折叠预览、场景控制、项目保存和设计预设，核对左侧工具与参数、中间画布、右侧预览的组织方式。

借鉴可学习的操作组织与流程，使用 BoxStudio 自身的毫米结构、图文、变量和导出引擎。没有复制对方资源或把不可执行的入口列为已完成能力。

## 用户可见变化

1. 顶部恢复盒型库、项目与继续编辑入口；返回盒型库会先保存当前项目。
2. 项目支持命名、保存、另存副本、恢复快照、JSON 备份与导入。打开项目之前保存切换前备份；无效 JSON、无效面板、无效结构或对象尺寸会拒绝导入。
3. 唛头页增加 SKU、QR 内容、重量、箱号、合同号、CRN、原产国、目的国、尺寸与单位表单。一次提交同步所有绑定位置，支持撤销和重做；错误数据不改变设计或历史。
4. 唛头预设使用同面对象避让和安全边距，空位不足时明确提示。Barcode + QR 插入和属性宽高调整保持 3.125 的组合比例。
5. 新盒型项目使用独立身份，结构尺寸同步到唛头尺寸。尺寸预设和手动参数修改都会真正重画刀版缩略图；无效尺寸阻止生成。
6. 导航和项目操作通过核心编辑器更新状态，避免整页重载。阶段切换自动适配画布；居中展示刀版；手机唛头组件可展开和收起，保留可用画布与属性区。
7. V66 加入既有共享调度器，没有新增 MutationObserver。以前的高级生产能力仍可访问。

## 明确边界与后续开发

- 已实现的参数化盒型为 8 个，不是原始需求中的 20–30 个。盒型工程扩充与实物打样仍是后续重点。
- 参考网站的全部功能没有逐项完成等价实现；未完成的模型交互不能视为已测试。
- 当前项目快照保存在浏览器；JSON 可跨设备恢复。公开在线服务、托管数据库、多人项目同步需要部署并验收后才能承诺可用。
- 条码比例和数字 PDF 测试不替代印刷样张的扫描等级；生产 PDF 的软件检查不替代刀模厂、印刷厂和第三方 PDF/X 验收。
- 本次手机验收是浏览器视口验收，不是实体手机触摸或硬件扫描测试。
