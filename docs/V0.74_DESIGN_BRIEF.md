# V0.74 工作台升级

使用者是制作纸盒印刷稿和运输唛头的包装人员，桌面上需要同时核对结构、变量、条码和实际毫米尺寸。独立唛头不依赖创建纸盒项目。

设计域：刀线、压痕、纸张、印刷面、图层、毫米标尺、正唛、侧唛、柔光棚。颜色来自白卡纸、浅灰工作垫、炭黑印刷、蓝色选区、牛皮纸棕色。沿用站内 studio tokens、细线分隔、四像素间距体系。

特征是中心毫米画布与左右独立滚动的工具区；正唛/侧唛切换在画布上方，两面共享运输信息，各自保存尺寸与对象。取代固定卡片高度、绝对定位预览按钮、无限扩张的盒型网格。素材名称和操作占独立行；盒型卡片垂直居中，桌面单行最多四列。

所有新增控件使用原生 button、select、input 与 dialog；短时反馈只动画 opacity，遵守减少动态设置。桌面、笔记本和手机均测试真实盒型、设计、唛头、素材、字体与灯光窗口的可达性。

资源只打包可核查许可的免费素材和 OFL 字体。平台数量与专有云端资源不宣称完全相同。参数盒型需要实际独立结构与折叠节点，不能用名称冒充新结构。
