# V0.61 Artwork Reference Convergence — Pacdora + Packform

## Product goal
BoxStudio remains a free-for-everyone browser packaging design studio. The primary path is intentionally kept simple:

**Choose structure → dimensions/material/thickness → dieline → 2D artwork → linked 3D → shipping marks → export**

V0.61 does not add production scheduling, capacity planning, ERP, MES or another factory-operations surface.

## Verified reference principles used by V0.61

### Pacdora
- Start with a real packaging structure/template instead of a blank CAD canvas.
- Dimensions/material/thickness are early, first-class decisions.
- Dieline generation and 3D validation are close together.
- Advanced structural controls are progressively disclosed after the simple start flow.
- Production-file handoff is a prominent completion action.

### Packform
- Structure, artwork and 3D stay in one project.
- 2D artwork is edited directly on the unfolded package.
- Text, image and color are normal design operations rather than separate subsystems.
- Image workflows include upload/placement/fit/opacity style controls.
- Geometry/artwork changes are checked through linked 3D.
- Professional line/curve/node tools remain available for users who need them.

## V0.61 decisions

### 1. First-class panel color
Panel color is stored as real Artwork data (`production-polygon`), not a temporary CSS preview. The same fill therefore enters:
- 2D Design SVG
- Artwork Atlas
- linked 3D texture proof
- SVG/PNG rendering
- Production PDF rendering

### 2. Unified Artwork Workspace
The normal Design view now groups the most common package-design actions together:
- target panel
- panel color
- quick color swatches
- current/all-panel color application
- text
- Logo/image
- Shipping Marks
- linked 3D

V0.60 remains the image/Logo implementation, including PNG/JPEG/WebP persistence and production output. V0.58 remains the Shipping Mark Studio, including variables, barcode/QR and Excel/CSV batch workflows.

### 3. 2D / 2D+3D / 3D views
Desktop defaults to a split design-oriented workflow using the existing live 3D proof; mobile defaults to 2D to preserve editing space. Users can move to full 3D without creating a detached preview project.

### 4. Existing professional capability is retained
Professional CAD, curve editing, topology, Preflight, collision/manufacturing/factory tools are not removed. They remain secondary/advanced surfaces rather than defining the default packaging-design experience.

## Acceptance requirements
V0.61 must prove that a panel color survives the full data path, not merely render a colored rectangle in one screen. Tests therefore verify:
- real state persistence
- 2D panel color
- Artwork Atlas polygon command
- linked 3D proof atlas
- geometry-resize synchronization
- all-panel application and clearing
- coexistence with V0.60 image artwork
- Production PDF generation
- all eight actionable real structure engines
- desktop and 390px Chrome without horizontal overflow

## Remaining parity gaps
This project does not claim complete Pacdora or Packform parity. Remaining work should continue to prioritize core packaging-design tasks such as richer artwork manipulation, typography/layout ergonomics, template breadth and reference-grade interaction polish before adding unrelated operations modules.
