# BoxStudio V0.29 Test Report

**Date:** 2026-10-04  
**Scope:** Resilient Excel/CSV import hardening against the original V1/V2/V3 batch requirements.

## Implemented

- Header Detection beyond row 1.
- Canonical bilingual header aliases.
- XLSX merged-cell expansion.
- Controlled business-field fill-down.
- TOTAL / SUBTOTAL / GRAND TOTAL / 合计 / 总计 / 小计 / 汇总 footer stop.
- Formula-without-cache diagnostics with Excel cell reference.
- Original source row tracking.
- Header-to-cell and canonical-field-to-cell lineage.
- Import diagnostics summary.
- Failed-row CSV export with preflight error context and lineage.
- Import diagnostics JSON export.
- V0.29 UI panel.
- Storage migration to `boxstudio-mvp-v29`.

- Production serializer remains `v0.27-native-cubic-production`.

## Explicit boundaries

This release does **not** claim the complete V3.0 Import Engine is finished. The following remain open:

- native `failed_rows.xlsx`;
- full Filter/Sort/Jump/Inline-correction Import Review table;
- persistent Mapping Profiles;
- configurable customer Alias Registry;
- leading-zero reconstruction from Excel number formats;
- arbitrary Excel formula calculation;
- automatic mapping of every preflight issue to one exact canonical cell;
- server-side import jobs / audit / identity / idempotency;
- browser interaction E2E for the import UI.

The Production PDF serializer is unchanged by this import-only release.
