# V0.76 对照增量与验收

本轮继续沿用 V0.75 逐站实际检查记录（Pacdora 150010、Packform ds.mxder、包小盒）。额外打开包小盒官方文字文档 https://help.baoxiaohe.com/archives/713/ ，核对字体、字号、粗斜体、字行间距、下划线、横竖排、对齐、颜色和文字旋转范围；打开 https://heropatterns.com/ 核对原版图案来源、作者及 CC BY 4.0 许可。没有声称验证参考站全部付费或登录后能力。

## 本轮落地

- 同一字体轮廓布局服务于纸盒画布、独立正唛/侧唛、SVG、普通生产 PDF、V19 PDF、V23 原生 PDF 和真实 3D 面板贴图。
- 文字框以毫米编辑字号、宽高、字间距、行高、左/中/右/软换行两端对齐、块垂直位置、颜色、真实常规/粗体、13度倾斜、下划线和删除线。横排按字符换行；竖排字符直立、列从右至左。倾斜是字形几何变换，不冒充独立斜体字体文件。
- FontFace实际下载，字体缺字、未加载、参数不合法、框溢出时阻止应用/印刷。修改先预览，一次历史事务应用；关闭丢弃草稿；正侧面与项目切换检查避免误写。
- 下载并保留87个Hero Patterns原始SVG，按固定源码版本转换曲线。保留填充规则、图块裁切及源透明度。原始哈希、来源与署名可检查。
- 底纹具有搜索、分类、24张分页、收藏、最近使用、实际毫米重复宽度、配色、透明底色、铺满印刷面、编辑已选素材。插入到纸面底色之上、图文之下；唛头下方的底纹被条码组合白底完整覆盖，移到组合上方会被遮挡检查阻止。
- SVG使用显式重复矢量路径，避免第三方转换器将SVG pattern低分辨率栅格化。PDF有真实曲线、原版透明度和署名；双面ZIP携带单独许可/署名文件。
- 原生对话框固定标题/操作区，内容内部滚动。桌面预览与参数分列，手机上下排列。尊重减少动效设置。

## 验收方法

- tests/v76.mjs：1,992项实际字形、12字体/两字重/方向/对齐/装饰组合、87原始文件哈希与曲线、独立面保存、真实贴图命令和PDF导出检查。
- tests/v76-files.py：238份独立600DPI MuPDF/CairoSVG比对，包括87原始SVG与转换后PDF、48种字体样张、普通/V19/V23输出及旋转。细线不同栅格器的抗锯齿采用一像素（0.0423mm）容差；每份至少99.5%墨色像素在容差内，精确像素重合另行记录，不能混作精确重合率。
- tests/v76-chrome-runner.mjs：1280×900、1024×768、820×900、390×844四种视口，真实点击、草稿取消、撤销重做、框溢出、库入口/搜索/分页/收藏/最近、面切换保存、原生下载完成、3D贴图像素及物理WebGL渲染。
- tests/v76-browser-files.py：独立读取Chrome完成的PDF/SVG/双面ZIP，在300DPI扫描CODE39与QR，核对内容和正侧面、字体轮廓、署名文件。
- 现有制造/CAD/结构、旧字体素材、编码、视频与渲染测试继续作为CI发布门禁。
