# BoxStudio V0.21 Development & Test Report

## Scope

V0.21 advances the V0.20 production-proof path in two areas: a real native PDF shading proof serializer and a substantially stronger Cross-panel editing model in the main 2D canvas.

This release intentionally does **not** relabel the existing production PDF as native-gradient production output. The tested V0.19 production PDF serializer remains the production route. V0.21 adds a separate native-gradient PDF proof/validation document so the new PDF shading objects can be exercised without weakening the established production path.

V0.21 also does not claim ICC RGB→CMYK conversion, varying-opacity gradient soft masks, calibrated monitor proofing, RIP trapping or physical board deformation simulation.

## 1. Native PDF Axial / Radial Shading Proof

Added `src/nativePdfV21.js`.

Supported PDF proof features:

- PDF `/ShadingType 2` axial shading for supported linear gradients;
- PDF `/ShadingType 3` radial shading for supported radial gradients;
- two-stop gradients through Type 2 interpolation functions;
- multi-stop gradients through PDF Type 3 stitching functions;
- native DeviceRGB shading resources;
- panel clipping;
- Cross-panel artwork clipping against the union of carton panels;
- solid vector fills;
- uniform artwork alpha through PDF `ExtGState`;
- panel-outline overlay for proof orientation;
- object-order traversal from the existing V0.20 z-order model.

The resulting file is exported as:

```text
boxstudio-v21-native-gradient-proof.pdf
```

### Native PDF proof boundary

The V0.21 PDF file is a gradient/appearance proof and serializer validation document. It is **not yet the complete production PDF** because it does not reproduce every production object handled by the V0.19 serializer.

The production PDF button therefore continues to call the V0.19 appearance-aware serializer.

Additional limitations:

- varying opacity between gradient stops is detected and reported; a true PDF soft-mask implementation is still required;
- non-uniformly scaled `objectBoundingBox` radial gradients are approximated as page-space circles in this proof serializer;
- imported artwork colors remain DeviceRGB;
- loaded CMYK ICC profiles are not used as an RGB→CMYK conversion engine;
- this does not represent Acrobat/callas/RIP certification.

## 2. Cross-panel Multi-select

Added `src/crossPanelTransformV21.js` and replaced the V0.20 runtime overlay with `src/v21CanvasOverlay.js`.

Cross-panel canvas editing now supports:

- Shift-click additive selection;
- Shift-click removal from an existing selection;
- persisted selection IDs;
- multi-object group translation;
- group selection bounds;
- single-object resize;
- aspect-lock resize;
- single-object rotation;
- configurable rotation snap step;
- selected object persistence through browser project state.

## 3. Panel-edge and Grid Snapping

V0.21 snapping evaluates:

- panel left/right edges;
- panel top/bottom edges;
- panel center lines;
- configurable mm grid.

Settings:

```text
snap
Grid mm
Tolerance mm
Angle step
```

Default values:

```text
snap = true
gridMm = 5
toleranceMm = 3
angleStep = 15
```

Holding `Alt` during move or rotation bypasses snapping for that interaction.

## 4. Canvas Handles

The V0.21 Cross-panel overlay includes:

- imported SVG outline preview;
- purple object bounds;
- lower-right resize handle;
- top rotation handle;
- green multi-selection bounds;
- temporary green snap guides.

The old V0.20 overlay module remains in the repository for history but is no longer loaded by `index.html`.

## 5. V0.21 Workspace

Added:

- `src/v21Ui.js`
- `src/v21Ui.css`

The workspace exposes:

- Native Gradient Proof PDF export;
- V0.20 Native Gradient SVG export;
- V0.19 Production PDF export;
- axial/radial shading counts;
- solid-fill and alpha counts;
- native-PDF warnings;
- Cross-panel snap/grid/tolerance/rotation settings;
- current multi-selection IDs;
- explicit color-management boundaries.

V0.20's workspace is hidden when V0.21 is active. The folded 3D artwork proof remains available.

## 6. Storage Migration

Primary browser state key:

```text
boxstudio-mvp-v21
```

`boxstudio-mvp-v20` and all earlier supported keys remain migration sources.

New state block:

```text
crossPanelEdit.selection
crossPanelEdit.snap
crossPanelEdit.gridMm
crossPanelEdit.toleranceMm
crossPanelEdit.angleStep
```

No IndexedDB artifact schema change is introduced in V0.21.
