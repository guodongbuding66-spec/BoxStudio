# BoxStudio V0.11 Development & Test Report

## Scope

V0.11 turns the V0.10 profile layer into an editable production workflow and adds a reusable batch/master-template pipeline.

## Added / upgraded modules

- `src/masterTemplates.js`
  - Schema v2 with backwards-compatible import of schema v1.
  - Rename, duplicate, revision creation, revision listing and restore-as-new-revision.
  - Portable Master Templates can embed active custom Customer Profile, Packaging Rule and Mark Template snapshots.
- `src/rules.js`
  - Project-local custom Packaging Rule profiles.
  - Required variables, fixed variables, CRN binding count, multi-package notice rule, Barcode+QR ratio/preset/aspect-lock rules.
- `src/customerProfiles.js`
  - Project-local customer profiles.
  - Customer defaults, linked Packaging Rule, preferred Mark Template and locked variables.
  - Switching profiles replaces stale profile locks instead of accumulating them.
- `src/markTemplates.js`
  - Save current mark elements/positions/variable bindings as a reusable custom Mark Template.
  - Apply and validate custom or built-in Mark Templates.
- `src/batchTemplates.js`
  - Apply a selected Master Template before writing each Excel/CSV row into variables.
  - Batch-wide Preflight summaries.
- `src/profileUi.js`
  - Customer Profile Builder.
  - Packaging Rule Builder.
  - Mark Template Builder.
  - Master Template rename / duplicate / revision / restore / import / export / delete.
- `src/v11BatchUi.js`
  - Batch Master Template selector.
  - Apply Master to current project.
  - Preflight all imported rows.
  - Master Combined PDF and Master PDF ZIP output.
- `src/v11Ui.css`
  - V0.11 management and batch workflow UI.

## Master Template revision model

A Master Template now contains:

- `revision`
- `revisionNote`
- `createdAt`
- `updatedAt`
- `parentId`
- `versions[]`
- optional embedded custom profile snapshots

Restoring an older revision does not destroy history. The selected historical snapshot is restored as a new current revision.

## Editable Packaging Rules

Custom rule profiles can define only verified data supplied by the user/customer/factory. V0.11 does not invent factory-specific crease compensation or die-board allowances.

Supported declarative checks include:

- required variable list
- fixed variable values (`key=value`)
- minimum repeated CRN bindings
- package index/count validity
- multi-package notice requirement
- Barcode + QR required state
- allowed size presets
- target aspect ratio and tolerance
- aspect-ratio lock requirement

All custom rules flow through the normal `runPreflight()` path.

## Custom Mark Templates

The current mark layer can be saved as a custom Mark Template, including:

- text / notice variable templates
- element positions and dimensions
- barcode/QR group settings
- shipping marks
- panel bindings

A portable Master Template embeds the active custom Mark Template definition so importing/applying the Master does not depend on an unrelated browser-local catalog entry.

## Batch Master workflow

When a Batch Master Template is selected, V0.11 builds each output state in this order:

1. clone the project state
2. apply the selected Master Template
3. restore embedded custom profiles when present
4. map the Excel/CSV row into live order variables
5. normalize variables
6. run Preflight or generate the requested PDF output

The Batch panel can run Preflight across all rows before generating a combined PDF or PDF ZIP.

## Storage migration

The browser storage key is now:

- `boxstudio-mvp-v11`

V0.10 and earlier keys remain migration sources.

## Automated coverage

CI runs:

1. syntax checks for all `src/*.js` and `tests/*.mjs`
2. legacy smoke tests
3. V0.10 profile/master regression tests
4. `tests/v11.mjs`

The V0.11 suite covers:

- Master schema v2 and schema v1 import migration
- rename / duplicate / revision / restore
- custom Packaging Rule creation and fixed-variable errors
- custom Customer Profile creation and stale-lock cleanup
- custom Mark Template snapshot/application
- portable Master embedded profile restoration
- Batch Master application before row variables
- batch-wide Preflight summary

## Remaining limitations

- Profiles and templates are still browser-local; there is no authenticated backend/account synchronization yet.
- Custom Mark Templates currently snapshot the mark layer rather than providing a separate free-form library editor canvas.
- Batch Master export adds production PDF workflows; a dedicated job queue/progress/cancellation layer is still pending for very large batches.
- Factory-specific structural compensation remains intentionally outside the automatic rules unless verified data is provided.
