# BoxStudio V0.12 Development & Test Report

## Scope

V0.12 focuses on operational reliability for larger production batches and on making customer/factory configuration portable instead of leaving every reusable object trapped in one browser profile.

## Added modules

### `src/jobQueue.js`

Adds a serializable batch-job model with:

- pending / running / completed / failed / cancelled states
- queue progress summary
- per-item file name and error metadata
- safe cancellation request
- cancellation finalization at row boundaries
- failed/cancelled retry reset

The browser UI intentionally yields to the main thread between rows. A single PDF build can still be CPU-bound, but the application no longer attempts to generate a large batch as one uninterrupted loop.

### `src/v12Ui.js`

Adds two production-facing workflows without replacing the existing V0.11 panels:

1. **Large Batch Queue** inside Batch Marks
   - Start / restart PDF queue
   - live percentage / completed / failed / pending counters
   - cancellation at a safe item boundary
   - successful pages collected into ZIP
   - cancellation creates a partial ZIP containing only pages that actually finished
   - rows with Preflight errors are marked failed instead of being silently treated as successful

2. **V0.12 Workspace Tools** inside Profiles
   - Workspace Bundle export / import
   - Mark Asset Library
   - Packaging Rule revision history / restore

### `src/profileBundles.js`

Adds a portable JSON bundle containing:

- custom Customer Profiles
- custom Packaging Rules, including revision history
- custom Mark Templates
- custom Mark Assets
- Master Templates
- active Customer / Packaging Rule / Mark Template IDs

Import supports deterministic `replace` and `skip` merge strategies. The UI currently uses explicit replace-on-matching-ID after user confirmation.

### `src/markAssets.js`

Adds a reusable mark-element library.

Built-in assets:

- This Side Up
- Fragile
- Keep Dry

A currently selected mark-layer element can be stored as a custom asset. The reusable asset removes project-specific position / panel binding and gets a new element ID when inserted.

This keeps the library element-based and compatible with the existing rendering engine rather than pretending arbitrary third-party SVG artwork is already supported by every export path.

### Packaging Rule revisions

`src/rules.js` now versions custom Packaging Rules.

Saving an existing custom rule ID creates a new revision and archives the previous verified definition. Revision metadata includes:

- `revision`
- `revisionNote`
- `createdAt`
- `updatedAt`
- `versions[]`

An archived revision can be restored as a **new current revision**, so restoration does not erase audit history.

Built-in rules remain immutable.

## Boundaries still enforced

- Queue persistence stores metadata, not generated binary PDF bytes. Reloading the page requires restarting the export queue.
- Cancellation is cooperative between row jobs; it does not interrupt a PDF serializer in the middle of one row.
- Workspace Bundle remains local JSON; there is no authenticated account/backend synchronization yet.
- Mark Asset Library stores supported BoxStudio elements. It is not yet a general SVG symbol editor.
- Factory-specific crease compensation, die-board allowances and machine corrections are still not invented automatically. They must come from verified production data.
- 3D print-texture mapping remains a later step; V0.12 does not claim full artwork-on-folded-carton rendering.
