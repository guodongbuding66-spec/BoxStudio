# V0.76 包装文字与底纹

使用者是需要输出真实尺寸印刷文件的包装设计、运输与外贸人员。任务是调整文字排版、添加可署名使用的底纹，并分别排正唛和侧唛。

Domain: 纸张、印刷面、版心、文字框、毫米、字形转曲、唛头、静区。Color world: 白纸、浅灰工作台、石墨墨色、牛皮棕、蓝色选择线、绿色检查提示。Signature: 以毫米文字框为比例的实际字形预览，正／侧唛共用数据但排版独立。

Defaults considered: 大面积装饰渐变、同尺寸功能卡片、面板悬浮遮挡画布。采用既有白纸工作台、真实底纹缩略图和原生对话框，自适应把预览与参数分列或上下排列。

文字组件 Intent: 先看真实字形，再调段落。Hierarchy: 最大区域为纸上字形；右侧328px控制栏。Palette: 复用现有paper/ink/selection。Depth: 单一浮层阴影，字段浅灰内嵌。Surfaces: 白纸与浅灰控制区。Typography: 现有BoxStudio UI SC，14px字段、12px说明、20px标题。Spacing: 4px网格，16px内距，24px区段。native dialog/fieldset/input/select/button，加载、空、错误、锁定、应用状态齐全。

底纹组件 Intent: 快速找原版素材并看实际平铺。Hierarchy: 左侧24张一页的素材，右侧244px实物比例预览与设置。Palette/depth/surfaces/type/spacing沿用文字组件。手机设置置于缩略图上方，不浮动覆盖。控件最少40px，偶发对话框180ms opacity/transform，reduced-motion关闭移动。搜索、分页、收藏、最近使用、透明底色、许可和署名均可见。

范围：横排字符自动换行、间距、行高、对齐、颜色、真实常规/粗体字形、13度倾斜、下划线、删除线；竖排字符直立、列从右至左。尚不包括OpenType竖排标点替代、混合富文本、阿拉伯连写。底纹为Hero Patterns 87款，不宣称复制商业站完整素材库存。
