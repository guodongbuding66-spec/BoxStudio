## Defect found during test

### Fold playback persistence

First Chrome run failed only at:

`Timeout: assembly animation`

The DOM showed the animation itself moving, but the persisted `foldProgress` did not deterministically reach 100 under headless virtual-time scheduling.

Repair:

- replaced requestAnimationFrame-only playback with deterministic timed increments;
- every step dispatches the same input event used by manual Fold control;
- completion explicitly persists 100%;
- manual 0/50/100 actions and slider pointer-down cancel a running animation.

The full Chrome chain passed after the product fix. The test assertion was not weakened.

### Inspector heading compatibility

Audit found that the existing Inspector predominantly uses `h3`, while the first V0.42 collapse styling only targeted `h4`. The selector was expanded to both heading levels and the real Chrome test now verifies the collapsed heading remains visible.
