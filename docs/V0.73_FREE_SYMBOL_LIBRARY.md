# V0.73 免费运输标识素材库

本轮继续核对 Pacdora 150010、Packform 和包小盒的公开页面：分类素材库、搜索、参数预览与拖入编辑器是本轮采纳的交互。Pacdora 模型页停留在构建模型，不能据此声称完整操作过它的模型。包小盒核对到高级参数盒型库；其他云端、付费和 AI 功能仍以 V0.71 验收矩阵标明的范围为准。

## 界面设计决策

按 interface-design 规范沿用现有纸张工作台：白色素材面、浅灰画布、深墨色图形，蓝色只用于操作链接与焦点。包装设计师先识别符号，再查看限制、插入或下载。主视觉是实际矢量标识，大图预览与编辑参数放在同一窗口；分类芯片、搜索计数和空状态承担导航，避免文字按钮挤成列表。使用 4 px 间距倍数、8 px 圆角、36/44 px 控件和原生 dialog，支持 Escape、键盘焦点与减少动效偏好。

## 实际素材与功能

- 下载并随项目保存 14 份 Wikimedia Commons 原始 SVG；12 份 CC0、2 份公有领域。原文件、作者、源页面、许可和 SHA-256 在 assets/handling-v73/sources.json，字体许可同目录保存。
- 上向、小心轻放、保持干燥、禁止手钩、禁止夹持、由此夹持、由此吊起、重心、怕晒、温度、禁止翻滚、禁止手推车、堆码重量和回收图形使用下载素材。
- 层数、高度、禁止堆码用导入图形组合；层数继续表示含底箱总数，不标为 ISO 2403 原图或认证。限制值使用 DejaVu Sans Bold 的正常字体矢量轮廓。
- 两个工作台共享分类、搜索、计数、空状态、大图参数预览、插入、透明 SVG 下载与素材来源窗口。独立唛头拖入毫米画布；纸盒拖入目标面板，位置受安全区与占用区检查，拥挤时选取同面安全空位。
- SVG、CMYK 矢量 PDF、Canvas 贴图使用同一套真实填充、孔洞、曲线与线宽。长方形对象内的符号保持比例。数字参数能继续编辑、撤销并随 JSON 保存。

现有 250×80 mm / 200×64 mm 条码与二维码组合、12 种生成码、扫描约束和 20 个真实盒型继续保留。无需账户、无付费入口。下载素材不依赖运行时访问第三方图片服务。

## 验证入口

`node tests/v73.mjs` 检查原文件校验、许可、矢量填充、参数、纸盒安全放置并输出生产 SVG/PDF。`python tests/v73-raster.py` 用 CairoSVG 与 MuPDF 独立渲染比较 17 种标识。`node tests/v73-chrome-runner.mjs desktop|mobile <Chrome路径>` 验证两个工作台、搜索分类、参数错误、拖放、撤销、原生下载和布局。V0.67–72 继续回归，实际生产 PDF 的 13 组编码用独立 ZXing 解码。

本地结果：121 项模型与素材检查通过；桌面 / 手机各 24 项浏览器检查通过，3 份原生下载逐字节核对；17 组独立 SVG/PDF 渲染最低重合度 99.285%。V0.67–72 模型回归、13 组独立 PDF 解码与桌面实际动画/下载回归通过。发布前继续运行 GitHub 全套验收与 Vercel 实际页面复核。
