# V0.74：两面唛头、资源与摄影棚

## 已交付功能

正唛与侧唛使用独立画板、尺寸、对象、选择状态和图层，共用项目名称、SKU、箱号、重量、尺寸和其他运输数据。旧单面 JSON 自动迁移；导入、自动保存、项目另存与撤销记录保留两面。侧唛提供标准和空白排版，不会替换正唛。当前面可单独导出 1:1 PDF、SVG 和 300/600 DPI PNG，也可一次下载包含两面 PDF/SVG 和完整项目 JSON 的 ZIP。

条码与二维码组合继续只接受 250×80 mm 或空间不足时的 200×64 mm，不能拆散。两面分别执行边界、静区、遮挡与编码检查，任一面的错误会阻止两面 ZIP 导出。

新增 32 份 Lucide 0.468.0 原始 ISC SVG，分类搜索、空结果提示、改色、插入印刷面和唛头、选中素材改色。曲线、端点和线宽使用同一编译数据输出 SVG、CMYK PDF 与 Canvas/3D 贴图。原文件、许可、作者与 SHA-256 均随站发布。原有 17 个运输标识与来源库保留。

新增纸工黑体、纸工宋体、Lato 和 Roboto Mono 四个 OFL 家族，每个家族提供真实 400/700 字重，共八份 TTF。中文版本覆盖 GB2312 汉字和常用拉丁字符；超出字集会给出缺字提示。字体按需加载，逐文字对象保存；SVG/PDF 和三维贴图采用实际字体轮廓，避免导出到另一台电脑后替换字体。仍支持用户自带 TTF。

盒型从 20 增至 24：双卷边翻盖盒、全深天地盖、带两块独立隔板的三格托盘、双壁展示托盘。每种结构包含真实独立几何、折叠树、刀线、尺寸补偿和组件装配。设计模板从 8 增至 16，新增咖啡、谷物、花礼、海洋护理、果园、珠宝、能源配件和再生纸品，每个图文对象均可编辑。

摄影棚使用随网站打包的 Three.js 0.180.0，MeshPhysicalMaterial、局部生成的 PMREM 环境、ACES 色调映射、主光/补光/轮廓光、真实模型投影。提供四个灯光方案，可调整方向、高度、亮度、色温、曝光和纸面粗糙度，参数用于场景 PNG 与 WebM。动画复用贴图和材质，仅更新折叠位置。透明 PNG 保留 Alpha。无 WebGL 2 的设备使用兼容渲染，灯光参数禁用并显示说明。视频通过随站发布的 Mediabunny 1.61.3（MPL-2.0）及 WebCodecs 固定时间戳逐帧编码，六秒为 72 帧，十秒为 120 帧，不受 GPU 渲染速度影响；无可用逐帧编码器时依次渲染全部 72/120 个动画姿态并请求录制每一帧，低性能设备只会增加导出等待时间；再保留编码帧顺序并重建完整时长和可寻址索引。原始依赖、许可和对应源码链接随构建发布。

## 布局修复

标识名称和预览按钮分别占独立网格行；固定高度与绝对定位不再让中文名称盖住操作。左侧颜色区改单列，色板自动换行，按钮不越出面板。批量唛头入口原有 nowrap 会超出滚动条预留区，现已允许换行。盒型卡片限制内容宽度并垂直居中，宽屏网格有最大宽度。正/侧唛标签、字体和素材窗口、三维灯光区均使用原生控件、局部滚动与手机布局。

## 验证

- V0.74 模型与资产测试：152 项，包含两面 JSON、非法面数据、真实字重、字形缺失、资源原文件哈希、SVG/PDF 输出、ZIP 格式和灯光范围。
- 24 种结构与 16 个设计：3,338 项尺寸、平面无交叉、真实折线、拓扑、装配、生产 PDF 和独立 Khronos GLB 验证。
- 四种窗口：1280×900、1024×768、820×900、390×844。检查真实点击、面切换和刷新保存、搜索、中文字体、原生两面 ZIP、完整标识名称与预览按钮分离、面板横向溢出、PBR 灯光像素变化和实际 PNG 下载。
- 36 组最终 SVG/PDF 使用 CairoSVG 与 MuPDF 独立栅格比对，最低墨迹重合率 98.204%。Python ZIP 读取器校验归档；ZXing 解码模型输出与四种窗口下载的正唛 PDF，均识别 Code39 和 QR。
- 六秒动画以 FFprobe 独立确认精确 6.000 秒、72 帧；另测十秒旋转视频、无 WebGL 与无 WebCodecs 的兼容视频，FFmpeg 解码首、中、末段确保画面变化。原有 V0.67–V0.73 模型、原生下载与真实视频回归继续运行。CI 保留此前制造、导入、颜色、印前与离线回归。
