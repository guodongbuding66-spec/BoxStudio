# V0.62 — Print Readiness Overlay / Reference Convergence

## Product scope

BoxStudio remains a free packaging-design studio. The primary user journey is:

**Structure → dimensions / material / thickness → dieline → 2D artwork → live 3D → shipping marks → preflight / export**

V0.62 does not add scheduling, capacity planning, MES, or factory operations.

## Public reference audit — 2026-10-07

The implementation was re-checked against publicly accessible product pages for:

- Pacdora — Dieline to 3D Mockup and structural packaging workflow
- Packform (`ds.mxder.com`) — online carton dieline editor / 2D + 3D workflow

The useful product patterns are treated as workflow references, not as permission to copy proprietary source code, brand assets, or exact trade dress.

### Reference patterns carried forward

1. Real structure and actual dieline are the source of truth.
2. Artwork lives on the dieline and is checked in 3D without creating a second project.
3. Print guides such as bleed, safe zone, panel boundary, cut and crease need to be visible near the artwork workflow.
4. Fold direction / folding animation belongs to the 3D proof workflow.
5. Production output must remain connected to the same project state.

## V0.62 implementation

### Print Readiness inside Artwork Workspace

The V0.61 Artwork Workspace now receives a dedicated Print Readiness strip with:

- Bleed overlay
- Safe-zone overlay
- Optional panel-boundary overlay
- Optional CUT overlay
- Optional CREASE overlay
- Actual bleed / safe values from the current structure
- Current printable-panel / CUT / CREASE counts
- Seam-continuity summary using the existing `bleedContinuity.js`
- Direct handoff to full 3D / folding animation
- Direct handoff to Preflight / Production PDF

Guide visibility preferences are UI preferences and are stored separately from production artwork. They do not mutate artwork elements or production geometry.

### Geometry ownership

V0.62 deliberately reuses:

- `buildLinkedWorkspaceModelV49()` for current parametric geometry / FoldGraph
- `state.structure.bleed` and `state.structure.safe`
- `buildBleedContinuityReport()` for artwork seam continuity
- V0.61 production artwork state
- Existing full 3D and production export surfaces

No duplicate dieline engine or duplicate preflight engine was introduced.
