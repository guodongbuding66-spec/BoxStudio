# V0.75 工作台与资源库

使用者：包装设计师和需要单独制作正、侧唛的外贸人员。关键动作是找结构、预览、创建副本、编辑与可靠导出。界面应像纸品样册和摄影工作台，安静、清晰、可核对。

领域：刀版、压痕、材质、印刷面、字样、运输符号、摄影棚。色彩世界：白卡纸、暖灰样册、牛皮纸、石墨标注、蓝色选择状态。签名：真实折叠几何的大幅模型预览与平面刀版切换。拒绝：七列狭小横卡、重复六步引导、文字徽章挤在操作按钮上。

沿用现有 studio tokens，8px 间距系统，1px 边界区分层次。标题和数据保持层级，数字使用 tabular-nums。阴影仅用于浮层；动效以 160ms opacity/transform 为主，尊重 reduced-motion。

组件检查点：
- 模型库：预览先于名称、描述、材质与动作。卡片正文居中、操作等高；桌面最多四列，手机单列。工具栏提供搜索、分类、3D/2D、收藏筛选与排序，状态应真实持久。
- 素材库：分类与搜索在上，矢量预览居中，分页避免一次创建上千 DOM，收藏/最近作为独立筛选；插入目标面和颜色有明确标签。
- 字体库：字体卡片展示真实已加载字形；先筛选，再预览用户输入，再应用当前文字。加载/缺字/锁定对象分别反馈。
- 摄影棚：预览画面是主区；灯光、镜头、纸面、台面和输出分别分组，参数必须实际改变渲染。WebGL 缺失时禁用物理材质控制。

验收：桌面 1280/1024、平板 820、手机 390，检查横向溢出、点击遮挡、焦点、原生下载完成、真实 SVG/PDF 字形与素材、折叠拓扑、图像像素变化及项目重开。
