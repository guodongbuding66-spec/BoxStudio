# BoxStudio V0.27 Development & Test Report

## Scope

V0.27 promotes the Bezier Cross-panel clip from the V0.26 proof route into the integrated production PDF path, carries that serializer into the recoverable Web Worker batch pipeline, and merges User Guide / Text Baseline / Rotation assistance into live canvas gestures.

V0.27 does **not** claim certified PDF/X, a general ICC CMM, arbitrary SVG filter/mask fidelity, server-side immutable approvals, or browser E2E coverage.

## 1. Native Cubic Clip in Integrated Production PDF

`src/productionPdfV23.js` now supports an opt-in `exportOptions.nativeCubicClip` production mode. V0.27 enables that mode through `src/productionPdfV27.js`.

For Cross-panel artwork with Bezier clip nodes, the production content stream now emits native PDF path operators for the object clip:

```text
m   move-to
l   line-to
c   cubic Bezier
h   close path
W n apply clipping path
```

This native clip is used in the integrated appearance path for:

- native axial gradients;
- native radial gradients;
- solid vector fills;
- varying-alpha soft-mask forms;
- Panel / primitive clip composition;
- DeviceRGB or verified DeviceLink DeviceCMYK appearance.

The same production PDF still contains the existing BoxStudio production content: CUT / CREASE / PERF / GLUE, spot separation resources, dieline overprint, marks, notices, barcode + QR, shipping icons, text outline modes and PDF/X-4 Candidate metadata/output intent when configured.

### Important outline boundary

Imported SVG outline fragments still use the existing `materializeCrossPanelArtworkElement()` fragment route, whose object clipping is based on the deterministic flattened Bezier polygon. V0.27 therefore makes the **appearance fill/gradient/soft-mask object clip native cubic**, while outline-fragment clipping remains the established flattened materialization path.

## 2. Production Serializer Identity in Approval Fingerprint

The V0.27 default project state now contains:

```text
exportOptions.productionSerializer = v0.27-native-cubic-production
```

`productionFingerprint()` already includes all `exportOptions`, so serializer identity is now part of the approved revision fingerprint without changing the approval API.

This prevents an approval made for a different serializer identity from silently authorizing a V0.27 Approved Production PDF. Existing revisions that no longer match must be revised and approved again.

Approved V0.27 exports record:

```text
serializer = v0.27-native-cubic-production
```

in the production audit event.

- `src/batchWorkerCore.js`

The Worker route now calls `buildProductionPdfV27()` for V0.27 jobs.

Existing behavior remains:

- TTF transfer;

```text

```

V0.24 jobs remain on their original V0.24 serializer for compatibility; they are not silently upgraded.

## 4. Live User Guide and Text Baseline Assist

Added `src/liveAssistV27.js` and replaced the active Cross-panel canvas overlay with `src/v27CanvasOverlay.js`.

During move gestures, the drag pipeline now composes:

```text
Panel / Grid Snap
→ Object Alignment
→ Equal Spacing
→ Persistent User Guide Snap
→ Text Baseline Snap
```

Persistent User Guides have priority over a competing text-baseline snap on the same Y axis.

Live guide colors remain semantically separated:

- cyan: persistent User Guide;
- violet: Text Baseline;
- magenta: object alignment / size match;
- orange: equal spacing;
- green: Panel / Grid snap.

Holding `Alt` bypasses live smart assistance for the current gesture.

## 5. Live Rotation Assist

Single-object rotate gestures now use the V0.26 deterministic rotation candidates in real time:

- configured angle grid;
- another Cross-panel object's rotation;
- +90° / +180° / +270° relative axes.

Object-to-object rotation continues to win ties against the plain angle grid.

The canvas displays a compact rotation-assist label while the gesture is active.

Current group-rotation behavior still uses the existing shared-transform angle-grid snap; V0.27 does not claim object-relative rotation assist for a multi-object rotation group.

Final automated scope is Syntax + Smoke + V0.10 through V0.27 module/regression suites.

## Known Boundaries / Next Work

- browser interaction E2E is still not executed in CI;
- Cross-panel outline-fragment clipping still uses deterministic flattened object-clip materialization;
- multi-object group rotation still uses the existing grid snap rather than object-relative rotation assist;
- ICC support remains verified DeviceLink LUT8/mft1 and LUT16/mft2 only;
- mAB/mBA, general source-profile → destination-profile CMM linking, black-point compensation and calibrated soft proof remain future work;
- PDF/X remains Candidate, not third-party certified output;
- no hosted backend, SSO, immutable server audit, cryptographic approval signature or collaborative guide objects are included;
- physical board thickness, bend radius and verified print-stretch compensation remain future work.
