# V0.78 折叠装配与完整实心素材库

## 动画

普通 3D 工作台、侧栏与 WebM 导出共用每条真实折线的分阶段时间轴。预折角耳、竖起前后壁、竖起侧壁、卷折内壁、预折盖翼、折入锁脚、合上盖板分别发生；多部件盒型最后移动上盖/内衬。高级逐折线编辑保留用户明确设置。

播放器提供暂停续播、倒放、0.25–2 倍速、3/5/8/12 秒、往返循环、连续进度拖动及阶段定位。视角在装配期间固定，不按每帧边界重新缩放。可显式适配当前姿态。减少动效偏好直接切换到终点；页面隐藏时暂停。侧栏播放器与主工作台共用同一实现。

新增纸厚补偿卷边翻盖盒和双壁托盘：外壁、纸厚桥、内壁、锁脚为四块连接面板，内壁向内偏移实际纸厚，锁脚落到盒底内侧。真实纸厚不通过重叠的两个零厚度面板冒充。两款为自定义参数化工程结构，需要制厂打样验证锁脚及加工容差。

## 素材

Lucide 0.468.0 全量 1544 款 + Tabler 3.31.0 Filled 全量 944 款，共 2488 款原版矢量。支持风格筛选、分类、搜索、改色、收藏、最近使用、原始 SVG 下载。纸盒和独立正/侧唛使用同一库。原始 SVG 集合、来源、作者、SHA-256 及 MIT/ISC 许可全部自托管。未导入参考站专有付费素材。

保留 87 款原始包装底纹、12 个真实字体家族/24 字重、32 款可编辑包装设计、8 套实体灯光及已有刀版、GLB、PNG/WebM 导出。

## 参考站核对与实际边界

本轮逐站打开：Packform 的尺寸/纸厚/高级刀版、字体/连续印刷、光源/地面、装配暂停/进度/0.1–2 倍速；Pacdora 的尺寸口径/材质/盒型分类/开合滑杆/AI-PDF-DXF-3D入口；包小盒的盒型/设计模板/场景/动画和渲染分类。当前浏览器 Pacdora 模型持续构建、Packform 3D 画布未正常显示，因此没有声称观看到其完整模型动画。用户提供 GIF 的当前文件仅一帧，依据可见卷边结构和网站实际控件设计，不推断缺失帧。

三站商业素材全集、全部数千盒型、摄影场景、AI 设计/拆图、协作/资产管理与印刷服务尚未完整对齐。当前 32 个真实参数化结构、2488 个可编辑矢量和上述自有资源均免费；不能将这些数量称为三站全量功能/素材。
