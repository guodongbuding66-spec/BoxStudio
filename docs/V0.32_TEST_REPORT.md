## 5. Validation boundary

Automated regression passing does not prove physical carton tooling correctness.

The new 0427 / RTE / Auto-lock engines remain:

`engineering-core-pending-real-sample`

Required external acceptance remains:

1. overlay with trusted CAD/dieline reference;
2. dimensional measurement;
3. fold sequence check;
4. board/caliper compensation check;
5. physical sample or converter review;
6. corrections fed back into template-specific allowance profiles.

Until that evidence exists, documentation and UI must not label these engines “factory certified”.
