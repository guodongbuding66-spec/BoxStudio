- Package Notice；
- CRN binding；
- Barcode / QR group。

### 3.3 Broken panel identity negative case

删除结构 CUT 后，旧 Panel 与新 bounded face 不能可靠一一对应。

最终行为：

```text

```

Production gate BLOCKED。

### 3.4 Orphan artwork negative case

如果 Artwork 仍引用已删除/无法确认的 panel：

```text

```

Full Production PDF BLOCKED。

## 5. CI 中实际发现并修复的问题

### Issue A — simplified fixture triggered real production Preflight

**症状**：V0.39 domain 第一次失败。  
**原因**：测试夹具删除 required marks。  
**处理**：保留 Preflight，拆分 geometry-renderer proof 与 real-production gate proof。  
**结果**：规则未削弱。

### Issue B — destroyed panel could be nearest-remapped

**症状**：破坏边界后仍可能找到 nearest old panel semantic。  
**风险**：Artwork 有机会被自动挪到错误结构面。  
**处理**：增加 fail-closed facade，未确认 old panel identity → `PANEL_REMAP_REQUIRED`。  
**结果**：生产阻断，等待显式人工 remap。

### Issue C — V0.38 version regression was tied to exact package version

**症状**：V0.39 升版后 V0.38 workflow 报：expected `0.38.0`, actual `0.39.0`。  
**原因**：旧测试把版本号当功能断言。  
**处理**：改为 package version >= 0.38.0，且 `test:v38` 必须保留；V0.38 功能 assertions 原样保留。  
**结果**：V0.38 gate 恢复正常。

## 6. Explicit Limitations

本测试报告不把以下事项标为已验收：

- true Polygon / Bézier offset；
- curved crease physical bend surface；
- fold-angle factory correctness when no semantic hint survives；
- external AutoCAD / ArtiosCAD / Esko round-trip；
- formal PDF/X validator；
- real RIP separation；
- physical barcode scanner grade；
- press proof / sample folding；
- real material/flute compensation matrix。

这些仍属于后续 software hardening 或 EXT。
