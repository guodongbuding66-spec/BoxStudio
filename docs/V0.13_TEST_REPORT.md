# BoxStudio V0.13 Development & Test Report

## Scope

V0.13 focuses on production hand-off reliability rather than adding another visual-only prototype layer. The release adds three operational capabilities:

1. cooperative pause / resume for the large batch PDF worker,
2. a panel-local mark layout editor,
3. production snapshots with submit / approve / reject / revision audit.

## Batch worker pause / resume

`src/jobQueue.js` now stores `pauseRequested` and supports:

- `requestQueuePause()`
- `finalizeQueuePause()`
- `resumeQueue()`
- `queueProgress().paused`

The browser worker in `src/v12Ui.js` checks the pause flag only at a safe row boundary. A PDF serializer already running for one row is allowed to finish; the next row is not claimed until resume.

Important limitation: generated binary PDF bytes remain in the in-memory JSZip instance. Therefore pause/resume is reliable inside the same page session, but after a page refresh the user must restart the queue. The persisted queue metadata does not pretend the binary archive survived reload.

## Mark Layout Editor

`src/markLayout.js` adds pure state operations for mark-layer elements:

- panel discovery from the current parametric geometry,
- absolute positioning with grid snap,
- nudge,
- resize with optional aspect lock,
- rotate,
- panel-safe alignment,
- duplicate,
- delete,
- move to another panel.

`src/v13Ui.js` exposes these operations as a panel-local SVG editing surface inside the Profiles workspace.

The editor supports:

- panel selection,
- visible Safe Area guide,
- click/select,
- direct drag,
- 1 mm nudge,
- left / center / right / top / middle / bottom alignment,
- ±90° rotation,
- duplicate / delete.

All committed moves are passed through `clampElementToPanel()` so the editor does not silently store marks beyond the panel rectangle.

The V0.13 canvas is intentionally an editing proxy for supported BoxStudio mark objects. It is not advertised as a general Illustrator-compatible arbitrary SVG authoring environment.

## Production Job / Approval / Audit

`src/productionJobs.js` adds a local production snapshot model.

A Production Job records:

- project / SKU / package metadata,
- Customer / Packaging Rule / Mark Template IDs,
- current Preflight error and warning summary,
- a deterministic production fingerprint,
- revision number,
- status,
- audit events.

Supported status flow:

- `draft`
- `submitted`
- `approved`
- `rejected`

A new revision can be created from draft, rejected or approved state. The new revision refreshes Preflight and fingerprint instead of mutating the previously approved fingerprint in place.

### Approval gate

The V0.13 `Approved Production PDF` action is enabled only when:

1. the active Production Job is `approved`,
2. the approved snapshot has no Preflight errors,
3. the current project fingerprint exactly matches the approved revision fingerprint.

Changing SKU, structure, artwork elements, customer/rule/template IDs, export settings or locked production variables invalidates the gate until a new revision is created and approved.

This is a local-browser audit workflow. It is not an authenticated electronic-signature or regulated approval system.

## Boundaries still enforced

- Batch pause/resume does not survive a full browser refresh with generated binary PDF bytes intact.
- Production approvals are local browser records; there is no user authentication or cloud audit server yet.
- Existing export buttons remain available for design/testing workflows; the V0.13 approval gate specifically protects the new `Approved Production PDF` action.
- Factory crease compensation, die-board allowance and machine correction data are still never fabricated.
- The current Three.js preview already paints supported mark objects on rectangular panel textures when Three.js is available, but V0.13 does not claim full arbitrary print-artwork texture fidelity across polygonal panels or the offline fallback renderer.
