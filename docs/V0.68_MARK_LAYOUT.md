# V0.68 唛头排版交互

日期：2026-10-08。基于 V0.67 工作台，继续免费、无需登录。依据 interaction-design Skill，保留原有工作台布局和短反馈动效，将交互集中在真实毫米画布。

## 已实现

- Shift / Ctrl / Command 点选、显式多选按钮、空白画布框选。手机通过多选按钮操作，无需键盘。选取不增加撤销历史。
- 所选对象整体拖动、方向键 1 mm 微移、Shift + 方向键 10 mm、毫米距离表单。移动在画布边缘停止，保持相对位置；边缘无效移动不增加历史。
- Escape 取消当前拖动，恢复可见位置且不写入历史；无拖动时清空选择。
- 左 / 水平中 / 右 / 顶 / 垂直中 / 底对齐。可相对所选范围，或画布 8 mm 安全区。
- 3 个以上对象水平 / 垂直等间距分布，保留两端位置。可用范围不足时拒绝分布，避免制造负间距。
- 10 mm 网格吸附；鼠标移动仅更新画布变换，结束后一次提交多对象修改。
- 复制、整组删除、图层上移 / 下移；Ctrl / Command + D 复制、A 选择可见可编辑对象。输入框仍保留原生文本快捷键。
- 图层锁定 / 解锁。锁定对象可见且输出到 PDF / SVG / PNG，禁止移动、修改属性、删除和重排；绑定的运输数据仍同步更新。复制锁定对象会创建可编辑副本。
- 隐藏对象立即移出当前选择；图层锁定状态随项目 JSON 保存和恢复。V0.67 JSON 继续兼容。
- 多选检查器显示整体位置与尺寸、移动距离、对齐目标、分布工具和锁定说明。选择框与框选辅助线仅在编辑画布出现，不进入生产文件。
- 纸盒手机组件窗口在打开时读取当前阶段，关闭 / Escape 时立即恢复素材节点，避免留下移出的素材或旧阶段内容。

## 验证方式

新增 `tests/v68.mjs` 有 63 项模型检查，覆盖相对位置、尺寸不变、边缘停止、锁定拒绝操作、项目兼容、图层顺序、物理 PDF 和无编辑辅助线的 SVG。全部本地 Node 套件通过；服务器启动脚本和依赖 PostgreSQL 的 V37 由相应 CI 验证。

`tests/v68-browser-e2e.html` 加载与主入口一致的 64 个生产脚本、60 个样式，分别以 1280 × 900 和 390 × 844 运行。验证实际 DOM 的多选、框选、拖动、取消、对齐、分布、锁定、撤销、数据同步和模式隔离，并生成截图。V0.65 原完整流程、V0.66 项目与数据、V0.67 独立唛头与四种下载字节、PDF Code 39 / QR 渲染解码仍在 CI 中执行。结果以对应提交的 GitHub Actions 为准。

本轮本地预览端口受到运行环境权限策略限制，浏览器验收通过 GitHub Actions 的 Chrome 执行，不将未执行的本地浏览器检查记为通过。
