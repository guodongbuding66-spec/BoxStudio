# BoxStudio V0.18 Development & Test Report

## Scope

V0.18 extends the folded artwork proof in three areas: safe SVG appearance parsing, fold/bleed continuity diagnostics, and explicit display-color pipeline boundaries.

This release intentionally does **not** claim complete Illustrator Appearance fidelity, ICC PCS display conversion, monitor-calibrated soft proofing, or automatic cross-panel artwork continuation.

## 1. Safe SVG Appearance Subset

Added `src/svgAppearance.js` and extended imported SVG marks with optional appearance metadata.

Supported preview appearance features:

- explicit solid fills on `rect`, `polygon`, `circle`, `ellipse`;
- simple closed M/L/H/V/Z path fills;
- linear gradients;
- radial gradients;
- basic geometric `clipPath` using rect/polygon/circle/ellipse;
- basic geometric mask treated as a binary clip in the proof renderer;
- inherited inline/presentation fill properties through SVG groups;
- element/group transforms for filled primitives;
- opacity / fill-opacity;
- safe warning collection for unsupported appearance constructs.

Security boundaries from the existing SVG importer remain in force: scripts, foreignObject, iframe, object, embed, raster image, use, external URL/data/javascript references remain blocked.

### Known SVG appearance boundaries

- embedded `<style>` selector rules are not evaluated;
- complex curved filled paths remain outline-only and raise a warning;
- gradientTransform is not yet applied;
- masks are binary geometric proof masks, not grayscale/luminance SVG masks;
- filters, patterns, blend modes and raster fidelity are not implemented;
- production SVG/PDF materialization still uses the existing outline-safe path and does not claim full appearance preservation.

## 2. Panel Artwork Atlas Integration

`src/panelArtwork.js` now emits `svg-appearance` commands in addition to the existing normalized commands.

The Canvas panel texture renderer can now render the supported SVG appearance subset before the texture is projected onto folded panels by `threeArtworkProof.js`.

`buildArtworkAtlas()` now also exposes an `appearanceCommands` count.

Existing text, icons, shapes, Barcode + QR and SVG outline commands remain available.

## 3. Fold Bleed Continuity Diagnostics

Added `src/bleedContinuity.js`.

For each fold edge, BoxStudio examines an artwork band on both connected panels. The default band is the structure bleed value.

Each seam is classified as:

- `two-sided`: artwork is present in the fold band on both panels;
- `one-sided`: artwork is present on only one side and requires review;
- `empty`: no artwork is present near the fold;
- `missing`: panel/hinge geometry is unavailable.

This is a production-review diagnostic. It does not automatically split or continue one image across panels.

## 4. V0.18 Workspace

Added:

- `src/v18Ui.js`
- `src/v18Ui.css`

The workspace shows:

- folded artwork texture proof;
- SVG fill / gradient / clip / mask counts;
- SVG appearance warnings;
- fold bleed continuity table;
- output ICC metadata when a profile is loaded;
- an explicit notice that Canvas proof remains an sRGB browser display path.

The V0.17 proof panel is hidden when V0.18 is active to avoid duplicate proof controls.

## 5. Display Color Boundary

V0.18 can surface the currently loaded output ICC metadata from `iccRegistry.js`, including profile name, color space, PCS and version.

The folded proof itself still renders through browser Canvas/sRGB. No ICC device-to-PCS-to-display transform is performed in V0.18. Therefore V0.18 must not be represented as a color-managed or monitor-certified soft proof.

## 6. Storage Migration

Primary browser state key:

```text
boxstudio-mvp-v18
```

V0.17 and all earlier supported keys remain migration sources.

No IndexedDB artifact schema change is introduced in this release.

- linear gradient parsing and stops;
- clipPath extraction;
- binary mask extraction;
- SVG mark appearance retention;
- Panel Artwork Atlas `svg-appearance` command generation;
- appearance command counting;
- quadratic SVG path endpoint regression;
- one-sided fold artwork detection;
- two-sided fold artwork detection;
- continuity summary output.

GitHub Actions continues running all earlier suites from smoke through V0.17 before the V0.18 regression.

Latest V0.18 CI run after enabling the new test completed successfully.
