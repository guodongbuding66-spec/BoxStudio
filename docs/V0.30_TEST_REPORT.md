# BoxStudio V0.30 Test Report

**Date:** 2026-10-04  
**Scope:** Close the remaining high-value Excel / Batch gaps from the original V1/V2/V3 development baseline.

## Implemented in V0.30

- Persistent local Mapping Profiles keyed by normalized Header Signature.
- One-time exact-header auto-apply for saved mappings.
- XLSX custom number-format parsing for explicit zero masks.
- Controlled leading-zero restoration with restoration diagnostics.
- Import Review row model with Filter / Search / Sort.
- Preflight issue → canonical field → source-cell hint where deterministically inferable.
- Open-row workflow from Import Review.
- Native OpenXML `failed_rows.xlsx` export.
- V0.30 browser UI for mapping profiles, zero-restoration diagnostics and review table.
- Storage migration to `boxstudio-mvp-v30`.

## Explicit boundaries

V0.30 does **not** claim the complete V3.0 Import Engine is production-final. Remaining boundaries include:

- server/customer-level Mapping Profiles and permissions;
- configurable Alias Registry;
- arbitrary Excel formula calculation;
- complex/scientific/date number-format recovery;
- schema-level canonical `field` on every preflight issue;
- inline correction and re-upload comparison;
- server ImportJob / identity / append-only audit / idempotency;
- large-workbook streaming/memory benchmark;
- browser interaction E2E.

The Production PDF serializer remains `v0.27-native-cubic-production`.
