## Bugs found by the real browser gate

### 1. Stale unauthenticated session refresh race

Initial implementation started `/session` probing when the Hosted panel opened. If the user logged in while that request was outstanding, a late 401 could overwrite newer authenticated UI state.

Repair:

- added a monotonic `refreshEpoch`
- stale async refresh results are discarded
- endpoint change / login / logout invalidate prior refresh operations

### 2. Authenticated browser client lifetime

The first UI implementation recreated a REST client on each refresh. Although the token was persisted, the active authenticated operation should not depend on reconstructing client state between login and session refresh.

Repair:

- reuse one Hosted API client for the active endpoint
- endpoint changes explicitly invalidate that client
- session token remains persisted for page reload recovery

### 3. Browser test clicked a temporarily disabled login control

The initial Chrome test only waited for `#v36Login` to exist. During the startup session probe, the control is intentionally disabled, so native browser `.click()` correctly performed no action.

Repair:

- E2E now waits for the login button to exist **and be enabled**
- business assertions were not weakened
- the test still performs the real UI login and approval path

## Security/authority statements supported by tests

V0.36 supports these claims:

- Role authorization is enforced on the server, not trusted from browser state.
- Approved content is tied to an immutable SHA-256 revision snapshot.
- A stale browser revision cannot silently overwrite newer server work.
- Revision author/submitter and approver are separated.
- Historic audit mutation is detectable by the hash chain.

V0.36 does **not** support these claims yet:

- crash-safe or multi-instance durable persistence
- database-level append-only/WORM guarantees
- distributed session storage
- production-grade authentication controls such as MFA, account lockout, IdP/SSO
- production TLS/WAF/secret-manager infrastructure
- durable Production Bundle/object-store archive

Those remain explicit V0.37+ work rather than being inferred from the in-memory hosted test service.
