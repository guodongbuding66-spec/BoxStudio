# BoxStudio V0.64 — Legacy UI Retirement & Editor Runtime Cleanup

## Goal

V0.64 reduces runtime duplication created by incremental UI layers from V0.58–V0.63 without deleting the production capabilities those layers introduced.

The focus is not a visual redesign. It is runtime cleanup with regression protection.

## Retired visible surfaces

The following historical surfaces no longer mount when the V0.64 runtime is present:

- V0.58 QuickNav
- V0.58 editor ContextBar
- V0.59 Guided Rail
- V0.60 standalone Artwork upload callout

Their replacement paths already exist in the consolidated workspace:

- V0.63 six-stage workflow navigation
- V0.63 live structure / artwork / preflight status
- V0.63 Context Inspector
- V0.60 Image toolbar handoff
- V0.61 Artwork Workspace
- V0.62 Print Readiness

This is different from V0.63, where several legacy surfaces were still created and then hidden by CSS. In V0.64 they are not created in the normal product runtime.

## Preserved capabilities

The cleanup deliberately preserves:

- Shipping Mark Studio
- template structure/configuration studio
- V0.58 live mini 3D proof
- V0.59 Simple / Professional UI mode
- PNG / JPEG / WebP artwork path
- panel colors and Artwork Workspace
- print guides / seam status
- unified stage navigation
- advanced manufacturing/factory/routing access

The old V0.58 `高级生产` button previously lived inside the retired QuickNav. V0.64 exposes the same state toggle from the V0.63 Context Inspector instead, so advanced V0.55–V0.57 tools remain reachable without restoring a second navigation bar.

## Shared UI runtime

Previously each of V0.58, V0.59, V0.60, V0.61, V0.62 and V0.63 created its own document-wide `MutationObserver`.

V0.64 adds `uiRuntimeV64.js`:

- one document-wide `MutationObserver`
- one microtask scheduler
- a callback registry
- per-module run counters
- mutation batch count
- error capture
- runtime stats exposed through `window.BoxStudioUiRuntimeV64`

V0.58–V0.63 register their existing enhancement function with this runtime when it is available. Their old private observer remains only as a compatibility fallback for isolated historical test harnesses or direct module use.

The normal V0.64 product path therefore changes the V0.58–V0.63 observer count from six document-wide observers to one shared observer.

## Loop protection

Shared scheduling makes accidental self-trigger loops more important. V0.64 avoids unconditional DOM text replacement in its own shell and the browser acceptance checks runtime stability at idle. A continuously self-triggering observer therefore fails acceptance instead of silently consuming CPU.

## Forward-version regression cleanup

V0.63 tests and workflow previously required the root package and page title to remain exactly V0.63. V0.64 converts that contract to `>= 0.63` while still executing the complete V0.63 model and browser behavior checks.

## Acceptance

The V0.64 model regression verifies:

- retirement policy
- preserved capability list
- shared observer module list
- one observer in `uiRuntimeV64.js`
- V0.58–V0.63 shared-runtime registration
- V0.58/V0.59 capability code remains present
- V0.60 image workflow remains wired
- runtime load order
- package version / test wiring

The real Chrome acceptance verifies on desktop and mobile:

- V0.64 runtime API mounted
- exactly one V0.64 shared observer
- V0.58–V0.64 callbacks registered
- retired surfaces are absent from DOM
- V0.61 Artwork Workspace remains mounted
- V0.62 Print Readiness remains mounted
- V0.60 image upload handoff remains functional
- advanced production toggle remains functional
- Shipping Mark Studio remains functional
- 3D, Preflight and Export stage navigation remains functional
- shared runtime does not continuously self-trigger at idle
- mobile width does not overflow

## Next cleanup candidates

V0.64 intentionally retires the first well-covered duplicate shell surfaces only. Older V0.11–V0.57 modules and CSS are not removed by version number alone. Future cleanup should continue from measured dependency evidence, splitting reusable capability code from obsolete presentation code before removing more script/style entries from `index.html`.
