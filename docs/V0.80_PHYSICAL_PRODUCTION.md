# V0.80: 平铺预览、真实几何与生产证据

## 实现

- 主预览、侧栏和独立场景共用展开姿态：整体旋转连续且保持铰链关系；外印刷面朝上、纸张平躺。完全成型姿态保持原结构结果。动画复用纸面和芯纸网格，以刚性变换驱动面板，避免每帧重建密集几何。导出视频也使用实际纸面最低点定位平台。模板弹窗仅内容区滚动，关闭按钮固定。
- 38 个实际参数化结构，新增三角、五角、六角、八角、十二角与梯形柱。边宽与转角来自真实截面；顶底图文裁剪并为文字保留安全区。新增结构需工厂打样。
- 激凸 / 激凹按对象的毫米深度改变正反面网格，保留纸厚；渐变边界与重新计算的法线。单 / 双 / 三层瓦楞切边有真实面纸、波形芯纸和空隙。
- GLB / OBJ / STL 本地导入，单位可选，文件 20 MB、25 万面限制。GLB 保留嵌入贴图，OBJ / STL 只导入几何。外部 URI、骨骼、压缩扩展拒绝并显示原因。对象储存在 IndexedDB。
- 场景 GLB 包含全部可见包装副本、道具与导入模型，嵌入贴图，单位米。局部工艺遮罩烘焙到透明度，纹理凹凸转为标准法线图并提供切线。不会导出摄影灯光、地面与舞台背景。
- 32 种纸材预设，11 种表面效果。5 组 ambientCG 实拍扫描 CC0 材质的颜色 / 法线 / 粗糙度 / 高度原始来源与 SHA-256 自托管；预览使用法线与粗糙度，颜色沿用用户纸色，纹理尺度由用户毫米参数控制。
- 包装专用库累计 277 个来源可核验的插画 / 标识，20 张产品照片。新增 129 个 Twemoji 原创矢量及 12 个运输 / 包材标识、8 张产品照片。版权、许可、原始链接和本地字节摘要随素材保存；Twemoji CC-BY-4.0，其他新增标识与摄影为 CC0 / 公有领域。素材许可不替代监管标识适用性审核。
- 160 款行业 / 品牌系列模板，包括新 20 系列各 4 个规格，具有不同版式、配色、插画与产品摄影；摄影嵌入项目以便导出和复用。新模板为原创配置。
- ZXing-C++ WASM 实际照片解码，同时核对条码与二维码的格式和内容；相同内容的两种码必须分别识别。用户可录入真实外部仪器报告和附件，保存到项目，原照片和报告留存在当前浏览器并可导出证据 ZIP。

## 验收与边界

- 模型测试覆盖全部 38 结构的平躺、面朝上与面板刚性，异形结构 GLB，几何压印、芯纸空隙、真实来源摘要和模板安全区。
- 141 个新增矢量分别用原始 SVG 渲染器和应用路径渲染器独立比对；浏览器验证实际控件、独立唛头、模型导入与刷新、原生下载和 Khronos GLB 验证。
- 原有完整中文字体、变量富文本、竖排标点 OpenType、HarfBuzz 连写与双向排版保留，并通过 V79 回归。
- 压印为有界高度场纸面网格，不是实体材料应力 / 模具加工仿真。扫描纸材并未提供经量测的纹理真实毫米标定；覆膜和工艺仍须实物打样。
- 场景快照 GLB 可跨设备分享；编辑项目 JSON 不包含 IndexedDB 内的导入模型二进制或印刷证据原文件，请分别下载场景 GLB 与证据 ZIP。
- 软件照片解码不生成 ISO/IEC 15416 / 15415 / 29158 仪器等级。测试中使用数字标签图片和明确标注的模拟报告测试文件，不冒充实物检测。
- 三家参考站的完整商业版权素材库尚未获得授权或全面覆盖；本版不能宣称其全部功能与商业素材已一比一复刻。
