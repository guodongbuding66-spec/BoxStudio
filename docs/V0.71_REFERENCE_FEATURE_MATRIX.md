## 验收方法

`tests/v71.mjs` 检查 20 个引擎目录、12 个新结构的不同实际几何、参数口径、边界、不相交展开面、真实铰链、多根装配、CAD 拓扑、生产 PDF 和 GLB。Khronos glTF Validator 检查二进制数据、法线、图文嵌入与格式引用。

`tests/v71-browser-e2e.js` 加载完整生产入口，覆盖桌面和 390px 手机：盒型配置 → 新设计 → 保存模板 → 从模板创建项目 → 真实场景 → 背景/透明/折叠/视图控制 → 实际 PNG/GLB 下载 → 独立唛头回归。实际下载的 GLB 再交给独立验证器，不能只验证内部模型对象。

既有版本测试、实际唛头 PDF 扫码、完整入口一致性、生产构建与 GitHub CI 继续保留。Vercel 生产部署以合并后的实际提交与 `release.json` 为准。
