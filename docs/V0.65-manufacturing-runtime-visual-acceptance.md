# V0.65 — Manufacturing Runtime & Visual Acceptance

## Product direction

BoxStudio continues the free packaging-design workflow:

**Choose structure → dimensions / material / thickness → dieline → 2D Artwork → Shipping Marks → linked 3D proof → Preflight → export**

V0.55–V0.57 remain advanced manufacturing tools and do not redefine the default product direction.

## Shared runtime consolidation

V0.64 consolidated V0.58–V0.64 under one document-wide `MutationObserver`. V0.65 extends that runtime upstream to the complete manufacturing dependency chain:

- V0.55 Manufacturing Intelligence
- V0.56 Factory Profile / Machine Capability Database
- V0.57 Factory Job Routing / Auto Factory Selection

The normal product path now registers V0.55 through V0.65 in one shared scheduler/observer. V0.55–V0.57 retain private-observer fallbacks only when loaded in isolation by legacy harnesses.

The visual harness was manually audited rather than trusting file existence alone. An initial selector bug caused advanced screenshots to match `body`, because `body.dataset.v55Manufacturing`, `body.dataset.v56Factory`, and `body.dataset.v57Routing` use the same attribute names as their feature surfaces. The final harness uses exact section selectors:

```text
section[data-v55-manufacturing]
section[data-v56-factory]
section[data-v57-routing]
```

Advanced screenshots are isolated from global simple/professional UI-mode rules only after the real sections and APIs have mounted.
