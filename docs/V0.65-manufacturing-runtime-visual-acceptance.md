# V0.65 — Manufacturing Runtime & Visual Acceptance

## Product direction

BoxStudio continues the free packaging-design workflow:

**Choose structure → dimensions / material / thickness → dieline → 2D Artwork → Shipping Marks → linked 3D proof → Preflight → export**

V0.55–V0.57 remain advanced manufacturing tools and do not redefine the default product direction.

## Shared runtime consolidation

V0.64 consolidated V0.58–V0.64 under one document-wide `MutationObserver`. V0.65 extends that runtime upstream to the complete manufacturing dependency chain:

- V0.55 Manufacturing Intelligence
- V0.56 Factory Profile / Machine Capability Database
- V0.57 Factory Job Routing / Auto Factory Selection

The normal product path registers V0.55 through V0.65 in one shared scheduler/observer. V0.55–V0.57 retain private-observer fallbacks only when loaded in isolation by legacy harnesses.
