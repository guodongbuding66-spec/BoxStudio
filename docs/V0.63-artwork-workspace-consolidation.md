# V0.63 — Artwork Workspace Consolidation

## Scope

The primary free workflow remains:

**Structure → dimensions / material / thickness → dieline → 2D Artwork → Shipping Marks → 3D proof → Preflight → export**

V0.63 does not add production scheduling, MES, capacity planning, or ERP behavior.

## Public reference review — 2026-10-07

The workflow was rechecked against publicly accessible Pacdora packaging editor / dieline-to-3D pages and Packform (`ds.mxder.com`). Pacdora publicly emphasizes a continuous browser workflow where a real dieline, artwork, 3D preview, folding direction/animation, material inspection and production output stay connected instead of forcing users to jump between unrelated tools.

## Consolidation decisions

### One visible stage navigation

Historical BoxStudio layers exposed multiple overlapping navigation systems:
- core Design / Structure / Marks / 3D / Preflight / Export tabs
- V0.58 quick navigation
- V0.58 structure context bar
- V0.61 Artwork Workspace navigation

V0.63 keeps historical DOM hooks for compatibility but exposes one primary stage bar:

1. Structure
2. Artwork
3. Shipping Marks
4. 3D Proof
5. Preflight
6. Export

The original tab buttons remain in the DOM so V49/V58/V61 programmatic handoffs continue to work, but they are no longer visually duplicated.

### Live workflow status

The stage bar surfaces:
- current structure and dimensions
- current artwork object count
- live Preflight error/warning state
- a context-aware Next Step action

The status is calculated from the current project state, existing linked geometry, V0.61 artwork statistics, and the existing production Preflight engine.

### Compact context inspector

The right panel now starts with a selection-aware Context card showing:
- selected artwork / panel
- object type
- bound panel
- object or panel dimensions
- Preflight status
- direct Artwork / Marks / 3D handoffs

Legacy Data / Layers / Project panels are still available, but are collapsed behind **Data / Layers** by default instead of permanently consuming vertical space.

### Image tool repaired

V0.60 already implemented real PNG / JPEG / WebP artwork, but the original core toolbar still rendered the Image tool as disabled. V0.63 removes that contradictory state and routes the toolbar Image action into the existing V0.60 upload pipeline. No second image-processing path is introduced.

### Artwork Workspace compact mode

V0.61 Artwork and V0.62 Print Readiness remain the functional surfaces. V0.63 removes duplicated explanatory headers and lets the unified stage bar carry workflow context, reducing vertical chrome without changing artwork data.

## Compatibility strategy

V0.63 deliberately does not delete historical V49/V58/V61/V62 modules yet. It first consolidates the visible shell while retaining old selectors and event targets. Historical layers can be physically removed later only after coverage proves the replacement path owns every required behavior.

## Acceptance

V0.63 adds model and real-Chrome acceptance for:
- all six studio stages
- all eight real parametric structure engines
- live Preflight summary
- selection context summary
- suppression of duplicate V0.58 navigation/context UI
- hidden-but-compatible original tab buttons
- collapsed secondary inspector panels
- V0.60 image-toolbar handoff
- stage navigation across Marks / 3D / Preflight / Export and back to Artwork
- desktop and 390px mobile overflow

V0.62, V0.61 and V0.39 remain explicit regression baselines in the V0.63 workflow.
