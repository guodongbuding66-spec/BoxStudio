## Defects found by the real-browser gate

### 1. Mutation decoration loop

The first implementation repeatedly rewrote a V0.42 legend from a MutationObserver. The rewrite triggered the observer again and starved the test/browser lifecycle.

Repair:

- every V0.43 decoration now has an idempotent dataset marker;
- already-decorated legend, warning and capability rows are not rewritten.

### 2. SVGPathElement `.click()` assumption

The next run reached the real native cubic path, but headless Chrome did not expose HTMLElement-style `.click()` on that SVGPathElement.

Repair:

- browser E2E dispatches a real bubbling/cancelable `MouseEvent` for SVG CAD edges.

### 3. Arc Inspector selection restore

Arc RX/RY/rotation were successfully persisted—the dumped DOM showed the edited path as:

`A 10 10 15 ...`

But V0.43 reopened the CAD view and attempted to restore the selected SVG edge with `.click()`, leaving the Inspector unselected in headless Chrome.

Repair:

- product code now has an SVG-safe activation helper;
- reopening CAD queues a real `MouseEvent` edge selection;
- Arc Inspector is restored after each persisted Arc edit.

The test assertions were not weakened for these defects.
