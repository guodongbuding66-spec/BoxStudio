# V0.77 几何、印刷和工作台升级

参考本轮 10 张用户截图及公开页面。结构页使用刀版参数栏、大画布、右侧 3D 开合和材质 / 文件入口。商业网站的私有素材与在线服务未视为已实现。

## 实际修复

- 修正面板外法线、折叠方向和印刷贴图朝向；内侧为空白纸色，切边具有真实纸厚。WebGL 和 GLB 使用相同三表面几何。
- 当前折叠渲染器读取真实进度；开合运行到中间帧和终点，手动调整中断动画。
- 侧栏画布按实际容器 / DPR 尺寸渲染；普通结构模式隐藏节点、面名与长期文字基线，保留真实尺寸与按需辅助线。
- 图片、文字、标识拖动使用边缘 / 中心吸附，6 屏幕像素容差，Alt 绕过；图片拖动提交为一次可撤销编辑。

## 新功能

- 8 种纸张及自定义预设：外侧、内侧颜色，纸厚、楞型和纸面效果，本地保存 / 重载。
- 24 种原创可编辑文字预设；同一文本对象按选中片段使用混合字体、字号、颜色及装饰，共享实际字形路径输出。
- 明确的 CAD 应用动作，重建面板和确认折线并同步 2D / 3D；无效面板或丢失图文归属会报告错误。
- 原尺寸 PDF 兼容 AI、PDF、DXF、GLB，以及额外 SVG 下载。AI 明确标注 PDF 兼容文件。
- 像素 / 毫米精确移动、方向键 1 px / Shift 10 px、六种对齐，适用于纸盒及独立正唛 / 侧唛。

## 验证

- 210 项字形、几何、纸厚、材质、刀版和吸附检查，Khronos 独立 GLB 验证。
- MuPDF / CairoSVG 9 组 600 DPI 混合字体、混合颜色和旋转对比。
- 真实 Chrome 检查开合几何 / 像素 / 中间帧 / 终点，38 项材质、原生下载、CAD、富文本、图片拖动、撤销及 4 种屏幕尺寸交互。
- 现有 V76 的 4 屏幕 132 项编辑、双面唛头、下载、字体 / 贴图及实体渲染回归通过。
- 完整生产入口桌面 / 手机的项目编辑、图片上传、条码遮挡阻止导出、解除遮挡后生成 PDF 流程通过。

## 范围

本轮继续使用已授权的本地素材与字体；三家参考站的全部私有素材、字体与专有在线服务尚未复刻。混合片段排版目前用于横排固定文本，变量文本和竖排使用现有统一文字样式。
