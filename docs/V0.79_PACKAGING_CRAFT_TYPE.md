# V0.79 包装素材、字形排版与局部工艺

工作台沿用纸白、石墨色和蓝色操作状态，保留原有原尺寸画布。行业内容直接进入可编辑的印刷面，材质和工艺同步实际 Three.js 预览。原生对话框保留键盘焦点、关闭和滚动行为；窄屏资源网格采用两列。

## 实现

- 18 个字体家族 / 39 个真实字重及字形文件。新增未经字符裁剪的上游黑体与宋体，分别包含 27,778 / 27,801 个汉字；400 / 500 / 600 / 700 按字体实际存在的字重提供。新增站酷小薇、马善政、阿拉伯文、天城文及 Lato 常规 / 粗体原生斜体。原 GB2312 字体保留。
- 自托管 HarfBuzz 14.6.0 实际 GSUB / GPOS 排版和 Unicode 双向处理。横排、竖排、富文本共享实际字形曲线；竖排采用 OpenType `vert` / `vrt2`，阿拉伯连接和天城文合字实际生成。换行只在字形簇边界发生；软换行后重新排版，样式片段保留行内上下文。
- 变量富文本记录源模板 UTF-16 范围。变量视为完整原子，数据替换后根据实际长度重新映射样式；编辑变量不会破坏后续片段。真实字重、颜色、字号、装饰同步 SVG、PDF 与 3D 贴图。
- 127 款 Twitter Twemoji 14.0.2 原版多色插画，包含食品、植物、节日、日化服饰；9 款公共领域 GHS 原版标识；12 张 Evan-Amos 等作者实际产品摄影，逐项验证 CC0 / 公共领域许可。保留原始 SVG 视口、路径、颜色和透明度。素材可以独立修改色块，或切换单色。SVG 元数据、PDF 路径内容和项目数据保留来源及许可。
- 16 个原创品牌系列 × 3 SKU，新增 48 款行业设计，总计 80 款。正面、背面、侧面分别排版；系列 SKU 有独立配色、产品素材、变量信息和实际尺寸。产品成分、净含量、使用信息以明确的待填写字段表示。礼盒品牌字应用局部烫金。
- 8 套客户唛头模板包含独立正唛、侧唛，客户名称、批次、订单、颜色、尺码、库位等字段可在数据面板更新；可保存 / 复用 / 删除自己的两面客户模板。250 × 80 mm 条码 / QR 固定组合保持完整，不拆分。
- 六类可调毫米纹理：细涂布、纤维、牛皮、布纹、帘纹、瓦楞。纹理重复尺度、强度和楞节距随材质保存；内外纸面有真实凹凸贴图，切边 UV 按边长与厚度映射瓦楞截面。
- 局部烫金、烫银、红金、UV、激凸、激凹。对象字形 / 曲线产生实际透明工艺遮罩，PBR 材质受真实灯光影响。文字、矢量素材、矩形和多边形支持工艺；运输标识与编码对象不允许应用局部工艺。
- 原尺寸工艺版 ZIP：按印刷面及工艺输出黑色矢量 SVG、毫米尺寸 / 对象 / 深度意图 JSON。工艺文字使用实际字体曲线。此导出为独立工艺版，不把局部工艺伪称为已嵌入 PDF 的专色。
- 场景支持最多 12 个附加对象：独立包装项目快照、方形 / 圆柱 / 球形道具和背景板。实际毫米位置、三轴旋转、比例、道具尺寸、颜色、显隐及删除；PNG / WebM 使用这些对象，设置与项目保存。GLB 明确只导出当前主包装。

## 许可与可重复来源

- `assets/fonts-v79/sources.json`：上游 URL、OFL 文件、源文件和静态字形 / 压缩文件 SHA-256、字符与汉字计数。`scripts/import-fonts-v79.py` 不做 Unicode 子集裁剪。
- `assets/packaging-v79/sources.json`：原版 SVG 来源、许可、作者和原始字节 SHA-256；CC BY 4.0 图形需保留素材署名。Twemoji 许可随站点自托管。
- `assets/packaging-v79/photos/sources.json`：逐张摄影许可、实际作者、上游原始 URL 和处理后的 JPEG SHA-256。照片插入项目后嵌入实际图像，离线导出无需第三方图片链接。
- `vendor/harfbuzz/LICENSE` 与 `vendor/bidi/LICENSE.txt`：真实排版引擎许可自托管。

## 仍有边界

- 完整字库指完整保留对应上游字体的字符范围，不等于覆盖所有 Unicode 汉字。缺字仍会明确报告。中文斜体提供几何倾斜；Lato 提供原生斜体。复杂语言已测阿拉伯文和天城文，不宣称所有语言、所有分行规则均已达到桌面排版软件水平。
- 激凸 / 激凹为法线扰动预览，并非改变纸面网格形成实际压印体积；瓦楞切边为按毫米尺度映射的截面纹理。真实纸纤维和物理压印仍需材料采样 / 实物打样。
- 场景已有附加对象编辑，不具备无限场景、任意外部 3D 模型导入、多包装 GLB、景深和完整渲染农场。
- 新增包装专用素材不能冒称三家参考站的完整商业库。现有 32 种盒型仍需持续检查各自装配、内衬与结构特例。此次没有新增盒型引擎或完整摄影灯光编辑器。
- 屏幕上的解码与印前检查不能提供实际印刷后的 ISO 条码扫描等级；需要印刷样本、扫描评级设备及测量报告。
