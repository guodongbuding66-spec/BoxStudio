## 5. Boundaries not claimed as tested

This regression is Node-based and does **not** constitute browser interaction E2E. In particular, CI does not physically drag the SVG group-rotation handle in Chromium/WebKit/Firefox.

V0.28 also does not claim:

- PDF/X certification;
- physical barcode/QR scanner verification;
- ISO barcode grading;
- calibrated monitor soft proof;
- hosted authentication/security validation;
- immutable server audit;
- print-factory acceptance.

These remain explicitly listed in the unfinished baseline audit.
