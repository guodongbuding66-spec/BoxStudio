# BoxStudio V0.40 Reference Re-study — Pacdora + Packform

Date: 2026-10-05
Status: Current product-direction addendum

## 1. Original requirement remains authoritative

BoxStudio is a free online paper-box design product inspired by the workflow strengths of:

- Pacdora dieline/template workflow
- Packform (`ds.mxder.com`) box-design / dieline-editing workflow

BoxStudio must also treat **Shipping Mark / 唛头 editing** as a first-class workspace rather than an afterthought.

## 2. Product access rule — FREE FIRST

Current product rule:

- All users can open the product without login.
- All design features are available without subscription.
- No approval/reviewer step is required for normal design or production export.
- No paid tier or paywall is part of the current product plan.
- Production export is blocked only by objective Preflight / structural errors.
- Hosted Auth/RBAC/Approval code from V0.36/V0.37 remains as an archived optional foundation and is **not** part of the default user journey.

This rule overrides the prior V0.36/V0.37 product direction that placed approval workflow in the main path.

## 3. Pacdora patterns re-studied from current public pages

Verified public workflow patterns:

1. Start from a very large template/dieline library.
2. Choose a box structure first rather than starting from a blank CAD document.
3. Customize dimensions, material and paper thickness.
4. Show updates immediately and support 3D preview as part of the same task.
5. Keep the creation path simple enough for non-CAD users.
6. Export production-oriented formats such as PDF / AI / DXF.
7. Keep structure, artwork and 3D mockup in one product rather than forcing app switching.
8. Support importing SVG/DXF dielines into a 3D folding workflow.
9. Let users set fold direction / material and inspect the assembled box.
10. Provide clear category discovery around common packaging use cases.

### BoxStudio interpretation

We should borrow the **workflow model**, not copy Pacdora branding, text, proprietary assets, or pixel-identical screens.

The BoxStudio version of this model is:

`Template → Size/Material → 2D Artwork → Dieline CAD → 3D → Preflight → Export`

The user should always know where they are in this flow.

## 4. Packform patterns re-studied from current public pages

Verified public capability patterns:

1. Parametric box structure with L/W/H and paper thickness.
2. Millimeter-based 2D artwork canvas.
3. Text, image, panel color and packaging artwork editing.
4. Editable dieline structure rather than a dead background image.
5. Node editing.
6. Straight line / arc / Bézier structure editing.
7. Add/delete ordinary nodes.
8. Cut/crease semantics and structural checks.
9. Bleed, safe-area and panel-boundary visibility.
10. 2D edits remain connected to 3D folding.
11. SVG dieline export.
12. Structure editing and artwork remain inside the same project.

### BoxStudio interpretation

This is the professional layer under the simple Pacdora-like workflow.

The default user can use the guided flow, while advanced users can open Dieline CAD and manipulate real millimeter geometry.

## 5. UI architecture for BoxStudio

### Global shell

- Clean white top bar.
- Product identity on the left.
- Core destinations in the center/left area.
- `FREE · No login · No approval` status visible in the shell.
- Export remains a high-visibility primary action.
- Hosted approval UI is not shown in the default application.

### Guided flow strip

Always-visible high-level steps:

1. 选择盒型
2. 尺寸 / 材料
3. 平面设计
4. 3D 检查
5. Preflight
6. 导出

This lowers the learning threshold without removing professional controls.

### Editor layout

Professional three-zone workstation:

- Left: tools / structure actions / reusable marks.
- Center: large 2D millimeter canvas or 3D stage.
- Right: selected-object / panel / structure inspector.
- Bottom: units, document size, zoom, status.

### Dieline CAD

- Left: Node, Edge, Geometry, Line Type, Production Offset tools.
- Center: dieline canvas with visible CUT / CREASE / PERF / GLUE plus Bleed / Safe polygons.
- Right: exact numeric inspector and Preflight diagnostics.
- Top: Preflight, SVG, DXF, Dieline PDF, Full Production PDF.

## 6. Interaction rules

- Dimension/material edits must update structure, not just labels.
- 2D changes must reach 3D.
- Dieline edits must rebuild panel topology and fold graph.
- Numeric inspector and direct manipulation must modify the same underlying model.
- Export must consume the edited model, not regenerate an old template behind the user's back.
- Undo/Redo is expected for editing actions.
- Object/Panel/Edge selection must remain visible and predictable.
- Preflight errors explain what is blocking export and point to the affected object/panel.
- Advanced controls should be discoverable but should not overwhelm first-time users.

## 7. V0.40 implementation decisions

Implemented in the V0.40 branch:

- Explicit free-public product policy.
- Default app no longer loads Hosted approval UI.
- Guided Template → Size/Material → Design → 3D → Preflight → Export strip.
- Refined clean workspace styling while keeping BoxStudio's own visual identity.
- Polygon Bleed / Safe offset engine.
- Miter / Bevel / Round joins.
- Offset self-intersection detection with bounded repair attempt and fail-closed output.
- Production Offset controls inside Dieline CAD.
- Bleed/Safe polygon overlays.
- V0.40 Preflight uses real offsets instead of the old `POLYGON_OFFSET_REVIEW` placeholder warning.
- Full Production PDF gate requires topology + offset + preflight success, not human approval.

## 8. Reference-study limitation

Public indexed pages were re-studied and used for the verified capability/workflow conclusions above.

A screenshot-by-screenshot live interaction audit of every Pacdora/Packform control is not yet claimed in this document because the metered interactive-browser wallet was unavailable during this pass. When interactive browser capture is available, the next study pass should record:

- exact editor panel widths and breakpoints
- hover/selected states
- menu depth
- template-card behavior
- dimension-control interaction timing
- 2D/3D switch transitions
- export modal hierarchy
- mobile adaptation
- keyboard shortcuts/tooltips

Until that visual pass is complete, BoxStudio should continue borrowing proven workflow principles rather than claiming pixel-level parity.
