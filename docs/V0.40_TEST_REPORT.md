## 3. 本轮测试实际发现的问题

### 3.1 V0.39 版本号硬编码

升级 package 到 `0.40.0` 后，V0.39 regression 原本要求版本必须恰好为 `0.39.0`，造成误报。

处理：

- 保留所有 V0.39 topology / artwork / PDF 实质断言；
- 改为产品版本不得低于 V0.39；
- 继续要求 `test:v39` script 存在。

没有通过删除 V0.39 功能断言来绕过回归。

### 3.2 iframe load 生命周期导致 E2E driver 饿死

第一版测试把完整 `index.html` 放在 iframe 中，并等待 iframe `load` 后启动 driver。

由于历史页面需要加载大量模块，Headless Chrome 的 virtual time 在网络阶段被冻结，导致 driver 长时间没有执行时机。

处理：

- 改为同文档、确定性真实模块顺序：
  `app → v35 → v36 → v38 → v39 → v40 → driver`；
- 仍运行真实业务模块；
- index.html 是否加载 V0.40 另由 CI 静态门检查。

### 3.3 Tab 重绘导致瞬时 DOM 引用失效

旧 `app.js` 切换 Tab 时会重绘整个 app/topbar。

真实 Chrome 在：

`Preflight active → 下一瞬间点击 Export`

时遇到旧 topbar 已移除、新 V0.40 topbar 尚未经 MutationObserver 注入的极短窗口。

处理：

- 每次页面重绘后等待当前 V0.40 控件重新出现；
- 不缓存跨重绘 DOM 引用；
- 不删除任何业务断言。

这也记录了后续 UX hardening 需要继续减少重绘闪烁。
