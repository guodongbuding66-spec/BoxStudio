# V0.69：角点缩放、专注画布与公开部署

纸盒设计与独立唛头设计共用顶部导航，项目和撤销历史分别保存。`/marks` 可直接进入唛头工作台，`/box` 可直接进入纸盒结构工作台；首次访问无需登录或购买。

## 本轮参考与实现

重新查看 Packform 的参数面板、画布工具条、对象属性、四角尺寸手柄和专注画布行为。Pacdora 公开页面可查看盒型分类、内外尺寸及生产尺寸说明和输出选项；此次浏览其 3D 初始化持续加载，因此没有把该页面完整交互列为已核实内容。

- 独立唛头单选对象出现四个可拖动角点；另一侧角点固定。文字和图形可分别改变宽高，按 Shift 保持比例；图片和搬运图标始终保持原比例。
- 条码 / QR 组合维持 3.125 比例及最小 100 × 32 mm。缩放限制在毫米画布内，锁定图层与多选不会出现缩放手柄。
- 指针移动只预览，释放后提交一次撤销记录。Escape 或指针取消还原预览。专注画布中首次 Escape 取消手势，再次 Escape 恢复面板。
- 两个工作台均可进入专注画布；面板恢复、适合窗口、选择与历史相互独立。保留数值属性作为键盘操作入口。
- Vercel 使用版本控制的静态构建和两个明确入口。部署输出仅含前端资产，排除服务端、测试、文档和开发数据。`release.json` 提供版本与提交号以核对线上构建。

## 验证方式与边界

`npm run test:v69` 检查四角锚点、比例、边界、无效输入、锁定、原数据不变、导出排除手柄，以及实际构建的依赖完整性。CI 使用完整生产模块运行桌面与手机 Chrome，检查拖动提交、撤销 / 重做、取消、锁定、条码、专注模式、工作台隔离、溢出与空闲稳定性。原 V0.65–0.68 浏览器验收保留。

项目保存在当前浏览器，可导出 / 导入 JSON 备份；本次公开版本没有部署多人同步数据库。独立唛头的批量生成、完整 Pacdora 模板库和所有参考站点功能仍未全部实现。中文生产 PDF 需要加载支持中文的 TTF；工厂打样和纸张实测不属于数字稿测试。
