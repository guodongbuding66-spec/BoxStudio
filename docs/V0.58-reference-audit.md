# V0.58 Reference Audit — Pacdora + Packform / 包小盒

Date: 2026-10-06

## Product goal

BoxStudio remains a free-for-everyone paper-box design studio. The primary workflow is deliberately narrowed to:

1. Choose a real packaging structure
2. Set dimensions / material / thickness
3. Edit the 2D dieline and artwork
4. Inspect the same project in 3D
5. Add/edit shipping marks, barcodes and QR
6. Preflight and export production files

No login wall, trial timer, paywall or download-count gate is introduced into the core workflow.

- https://www.pacdora.com/tools/custom-box-builder
- Public Pacdora editor screenshots indexed by Pacdora pages/search.

Confirmed public patterns:

- Very short dieline flow: template → dimensions / thickness / material → generated dieline → export.
- Production-oriented export is first-class: AI, PDF and DXF are repeatedly surfaced.
- Dieline and 3D preview are presented as one workflow rather than separate products.
- Public editor screenshots use a large neutral 2D canvas, compact floating controls, and a right-side 3D/export card.
- Custom size supports a direct numeric form with immediate visual feedback.
- Dieline-to-3D supports SVG/DXF upload, fold direction/animation and material selection.
- The product deliberately reduces packaging-engineering complexity at the first level of UI.

### Packform / 包小盒 lineage

- https://ds.mxder.com/
- https://www.baoxiaohe.com/templates/532
- https://print.baoxiaohe.com/
- https://help.baoxiaohe.com/support/archives/868/
- https://help.baoxiaohe.com/archives/2671/

- Public editor screenshots/videos indexed for 包小盒.

Confirmed public patterns:

- Editor shell is strongly tool-oriented: left-side assets/text/background/upload, central dieline/artwork canvas, right-side properties / 3D preview.
- Template browsing supports search and category-driven discovery; a template is an immediate entry to editing.
- 2D design and 3D result stay tightly connected.
- Text, image/material assets and background are treated as direct design primitives.
- Public materials explicitly show barcode generation as a packaging-design operation.
- Print guidance is embedded in the product context: CMYK, single-black QR/barcode, safe distance, vector artwork and resolution expectations.
- Template → design → 3D → export/printing is a continuous journey rather than a collection of unrelated engineering pages.

## Adaptation rules for BoxStudio

This is a functional/UX reference, not a pixel-for-pixel or branded copy. BoxStudio should preserve its own visual identity and its verified geometry/production engines.

### Keep on the first level

- Structure library
- L / W / H
- internal / external / manufacturing size basis
- material / flute / thickness
- 2D dieline/artwork
- live 3D
- shipping marks
- PDF / AI-compatible / DXF / SVG production export

### Move out of the first level

The V0.55–V0.57 manufacturing/factory/routing tools remain useful but should be collapsed under an explicit **Advanced Production** control. They must not visually compete with the basic packaging-design journey.

### Editor layout target

- **Top:** compact project/structure context + core journey navigation
- **Left:** direct design tools with text labels, not ambiguous icon-only buttons
- **Center:** dieline/artwork canvas remains dominant
- **Right:** property inspector plus a small live 3D quick preview in 2D/Marks modes
- **Full 3D tab:** remains available for linked panel selection and fold inspection

### Shipping-mark editor target

Shipping marks become a first-class design mode. Common presets should be insertable in one click onto a selected panel:

- SKU
- N.W. / G.W.
- L × W × H
- Package X/Y
- Contract No.
- CRN
- Made in
- Destination
- variable text
- Barcode + QR
- This Side Up
- Fragile
- Keep Dry

Existing Excel/CSV mapping remains the batch-data path.

## V0.58 implementation scope

- Light neutral packaging-workbench visual hierarchy based on the observed reference patterns.
- Compact core navigation: Structure Library / 2D / 3D / Marks / Export.
- Current structure context strip with dimensions/material summary.
- Left tools gain explicit labels.
- Design and Marks modes receive a live 3D quick preview in the right inspector.
- Marks mode receives a dedicated Shipping Mark Studio with target-panel selection and one-click presets.
- Print advisory block added to Marks mode.
- Template center receives a compact six-step packaging journey header.
- Advanced manufacturing/factory/routing panels are hidden by default and exposed through Advanced Production.
- Existing verified geometry, 2D/3D linkage, preflight and production export paths are retained.

## Validation policy

V0.58 must not be accepted by static DOM checks alone. Acceptance requires:

- model tests across all eight real parametric structures;
- mark presets remain inside target panel bounds;
- real Chrome desktop workflow;
- real Chrome 390px workflow;
- mark insertion persists across reload;
- live quick 3D actually mounts a canvas;
- template search still works;
- export entry still works;
- V0.39 real CAD → topology → Production PDF remains green;
- V0.57 remains forward-compatible.

## Research limitation in this pass

The current public/cached pages and screenshots were available and were used to ground the redesign. A metered live browser click-through session was not available in this pass, so this document does **not** claim that every current Pacdora/Packform modal or authenticated interaction was exercised. A live click-through audit should be added later as a second fidelity pass; the code and tests in V0.58 are intentionally based only on behavior that was observable from public sources or already verified in BoxStudio.
