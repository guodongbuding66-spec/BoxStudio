# BoxStudio V0.5 test report

## Automated checks

Command:

```bash
node tests/smoke.mjs
```

Expected result:

```text
BoxStudio V0.5 smoke tests passed
```

Coverage:

- Built-in RSC and Mailer Fold Graph have nodes, hinges and physical hinge geometry.
- Mailer 150010 default design area remains 576 × 590 mm.
- Code 39 / EAN-13 / UPC-A / ITF-14 / GS1-128 generate valid bar layouts.
- Invalid EAN check digit is rejected.
- GS1 GTIN check digit and YYMMDD date rules are checked.
- SVG transform helper handles translate / scale / rotate matrices.
- CREASE + adjacent panel geometry produces fold candidates.
- Confirmed imported candidates build a connected Fold Graph from selected root.
- DXF sample parses CUT / CREASE and panels.
- Bleed / Safe geometry is generated and Safe Area checks work.
- Single-page and multi-page production PDFs are built.
- R12 DXF is built.
- Native cubic Bezier survives document model and is flattened only at PDF/DXF production output.

## Browser-only features

The following require a normal browser runtime and are not fully exercised by Node smoke tests:

- DOMParser-based SVG file import.
- Dragging Bezier control handles.
- localStorage persistence.
- PNG export through Canvas.
- Offline Canvas 3D pointer rotation / wheel zoom.
- Optional local Three.js renderer.

These features are implemented but should be verified in the target deployment browser before production use.

## Production warning

The supplied source carton PDF does not contain a complete corrugated-board compensation table. Parameterized structures in BoxStudio remain engineering bases, not signed-off cutting dies.
