# BoxStudio V0.22 Development & Test Report

## Scope

V0.22 focuses on the two remaining editing/appearance gaps left after V0.21: varying gradient-stop alpha and shared multi-object Cross-panel transforms. It also introduces an editable per-object geometric clip polygon that is consumed by cross-panel materialization and the folded 3D artwork path.

The release deliberately keeps a strict distinction between the established production PDF serializer and the newer native-gradient proof serializers. V0.22 does **not** claim that native PDF shading has replaced the complete V0.19 production PDF route, and it does not claim ICC RGB→CMYK conversion or certified PDF/X output.

## 1. Native PDF Gradient Soft-mask Proof

Added `src/nativePdfV22.js`.

V0.21 already emitted native PDF axial/radial shading and uniform alpha through `ExtGState`. V0.22 adds a varying-opacity path for gradient stops:

- varying stop opacity is detected from the parsed SVG gradient;
- a parallel DeviceGray axial/radial shading is generated from stop opacity values;
- the gray shading is rendered inside a transparency Form XObject;
- the Form is attached through `/SMask << /S /Luminosity ... >>`;
- the color gradient remains a native DeviceRGB PDF shading;
- the same panel/object clipping geometry is reused for the soft-mask content.

Export file:

```text
boxstudio-v22-native-gradient-softmask-proof.pdf
```

### Soft-mask boundary

This is a native PDF appearance proof/serializer-validation path. It still does not reproduce every production object from the V0.19 production PDF serializer. It therefore remains separate from the stable Production PDF button.

The soft mask is built from explicit gradient stop opacity. It is not a full implementation of arbitrary SVG luminance-mask trees, filters, blend modes, raster masks or CSS compositing.

## 2. Shared Cross-panel Transform

Added `src/crossPanelTransformV22.js` and `src/v22CanvasOverlay.js`.

New multi-object operations:

- shared group resize around a common transform origin;
- shared group rotation around the selection center;
- shared rotation snap using the existing angle-step setting;
- group resize handle on the multi-selection box;
- group rotation handle on the multi-selection box;
- existing Shift-click multi-select and group translation remain active.

The V0.21 single-object resize/rotate behavior remains available when only one Cross-panel object is selected.

## 3. Alignment and Distribution

The V0.22 workspace exposes deterministic multi-object alignment:

- Align Left;
- Center X;
- Align Right;
- Align Top;
- Center Y;
- Align Bottom;
- Distribute X;
- Distribute Y.

Distribution uses equal inter-object gaps across the current selection span.

## 4. Editable Per-object Clip Polygon

V0.22 adds `crossClip` to Cross-panel artwork objects.

The editor accepts normalized object-space polygon coordinates, for example:

```text
0,0 1,0 1,1 0,1
```

A built-in 10% inset preset is also available.

The clip polygon:

- scales with the object;
- rotates with the artwork;
- clips supported fill fragments;
- clips imported SVG outline segments;
- is applied before panel clipping;
- therefore propagates into V0.19 production materialization and the folded 3D Panel Artwork Atlas.

`src/nativeSvgV20.js` was also updated so Native SVG export retains the editable Cross-panel clip as a document-space clipPath around the native appearance layer.

This is a geometric object clip. It is not RIP trapping or an arbitrary luminance-mask editor.

## 5. V0.22 Workspace

Added:

- `src/v22Ui.js`
- `src/v22Ui.css`

The workspace exposes:

- V0.22 Native Gradient + Soft-mask Proof PDF;
- V0.20 Native Gradient SVG;
- stable V0.19 Production PDF;
- soft-mask count;
- selected-object count;
- editable clip count;
- alignment/distribution controls;
- normalized clip-polygon editor;
- 10% inset clip preset;
- clip clearing.

V0.21/V0.20 workspaces are hidden when V0.22 is active. The folded 3D proof remains available.

## 6. Storage Migration

Primary browser state key:

```text
boxstudio-mvp-v22
```

`boxstudio-mvp-v21` and all earlier supported keys remain migration sources.

No IndexedDB artifact schema change is introduced in V0.22.

## 7. Automated Regression Coverage

Added `tests/v22.mjs` covering:

- varying gradient-stop opacity detection;
- PDF `/SMask` generation;
- PDF `/S /Luminosity` soft-mask semantics;
- grayscale transparency Form XObject;
- native axial shading still present in the color path;
- shared multi-object scaling;
- shared multi-object rotation snap;
- alignment;
- equal-gap distribution;
- normalized clip parsing;
- Cross-panel clip persistence;
- measurable reduction in materialized fill area after clipping;
- Cross-panel clip diagnostics.

GitHub Actions continues to run syntax checks, smoke tests and every regression suite from V0.10 through V0.22.

## Known Boundaries / Next Work

- merge native PDF shading/soft masks with every complete production-PDF object and PDF/X Candidate resource;
- implement real ICC-managed artwork color conversion with a verified color-management engine;
- implement arbitrary SVG luminance masks instead of the current gradient-opacity soft-mask subset;
- add graphical clip-path point editing directly on the 2D canvas;
- add smart spacing guides while dragging, not only command-based align/distribute;
- add shared non-uniform rotation-aware transform boxes;
- add board thickness, bend radius and verified print-stretch simulation;
- hosted backend, Auth/SSO and immutable server-side approval audit remain future infrastructure work.
