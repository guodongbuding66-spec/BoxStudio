# BoxStudio V0.47 — Pacdora / Packform Reference Gap Matrix

## Product rule

BoxStudio is being built as a **free-to-everyone packaging design studio**. Reference products are studied for workflow, information architecture and interaction patterns; their branding/trade dress and paywalls are not copied.

BoxStudio Free policy:

- No account required for core/local workflows.
- No watermark.
- No export paywall.
- SVG / PDF / DXF / PNG / Production PDF remain available without a paid tier.
- Local project snapshots work without cloud identity.

## Live-reference observations

### Pacdora dieline detail/editor

Observed pattern:

- Resource/category discovery on the left.
- Large 2D dieline workspace in the center.
- 3D and download/export on the right.
- Manufacturing / inside / outside size distinction.
- Material presets that affect preview.
- Dieline line legend and compact pan/zoom canvas controls.
- AI / PDF / DXF / 3D-oriented export cards.
- A fuller online-design entry for artwork editing.

### Packform / DS.MXDER workbench

Observed pattern:

- Persistent project switcher: New / Save / Rename / Save As / Open.
- Left vertical tool rail + parameter inspector.
- Central 2D dieline editing and right-side persistent 3D preview.
- 2D / 3D mode, focus mode, ruler and panel settings.
- Numeric dimension inputs plus drag sliders.
- Manual/automatic bend radius and paper-thickness-aware calculations.
- Advanced flap/tuck parameters.
- Per-face color controls.
- Object inspector with exact X / Y / W / H / rotation and font controls.
- Layers/object management.
- Assembly animation.
- 3D scene controls: contrast, ground, face orientation, ground distance and lighting modes.
- Explicit dirty/unsaved indicator.
- Freemium limitations on project/render/export usage.

## V0.47 acceptance priorities

V0.47 is not “reference parity complete” until these are true:

1. Existing V0.36–V0.46 regressions remain green.
2. Template discovery works by category and search.
3. Actionable templates show an actual dieline preview.
4. Quick setup recomputes geometry when L/W/H, size basis or material changes.
5. Inside/manufacturing/outside sizes are simultaneously inspectable.
6. Local project New / Save / Rename / Save As / Open works without authentication.
7. Shipping marks, barcode/QR and batch marks remain available.
8. Professional Layers / Objects / exact transform editor is reachable from the main workflow.
9. Linked 2D↔3D review is reachable from the main workflow.
10. Production exports are enabled and contain no pricing/login gate.
11. Real-browser tests verify the interaction path, not only module imports.

## Next closure targets

### V0.48 candidate — Parametric Packaging Controls

- Unified L/W/H number + slider controls.
- Board-thickness-aware bend-radius model shared by 2D and 3D.
- Advanced flap/tuck parameters with safe geometry ranges.
- Per-face material/color controls.
- Live rebuild debounce and constraint validation.

### V0.49 candidate — Render & Presentation Studio

- Ground plane, orientation and distance.
- Lighting presets.
- Contrast/exposure controls.
- Higher-quality render/export preview.
- Saved camera presets.

### Template program

Grow only with verified parametric engines or clearly labelled schema-only references. Do not fabricate production geometry merely to inflate template count.
