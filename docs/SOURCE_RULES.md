# 上传模板已确认规则

依据用户上传《美线侧封箱印刷模板20260520(1).pdf》整理。以下规则只来自源文件明确内容：

- 五层 BC 楞
- 耐破强度 250 磅力/平方英寸
- 单位：mm
- 公差：±5 mm
- 印刷：单黑
- 字体：Arial 或接近，字号随外箱尺寸匹配
- 典型字段：SKU / N.W. / G.W. / Package Meas / CRN / Contract No. / Made in China / US
- 条码 + 二维码要求整体等比例缩放至 25×8 cm；空间不足可等比例缩放至 20×6.4 cm
- 禁止拆分条码、二维码摆放至其他位置
- 需要确保条码、二维码易扫描
- 多包裹时显示英文包裹提示，单包裹时不显示
- 原产国需要随货源地国家改动
- 生产工厂报海关备案编码需要联动修改，共 2 处

## V0.7 结构说明

源 PDF 页面包含刀版示意，但可解析内容并未给出完整的结构尺寸链、压线补偿表、设备工艺余量或所有节点坐标。因此当前参数化侧封箱 / RSC 几何属于工程基础模型，用于实现 L/W/H/T/Glue 重算与后续结构引擎，不宣称与源刀版 1:1 等价。
