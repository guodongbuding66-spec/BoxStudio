# BoxStudio V0.40 实施计划

## 目标

把已有 V0.32–V0.39 的功能重新组织成一套接近成熟包装设计软件的统一体验，而不是继续叠加独立入口。

**版本名**：V0.40 — Pacdora/Packform UX Convergence + Free Professional Workflow

## 产品约束

- 所有人可免费使用核心功能；
- 不做 premium / subscription / watermark / export quota；
- 不要求审核通过才能导出；
- 不要求 Approver / Operator 等角色才能完成本地生产流程；
- 登录仅用于云同步等可选能力；
- Preflight Error 可以阻断明显错误生产文件，Warning 不阻断。

## Phase A — Editor Shell

1. 顶栏：项目名、Undo/Redo、保存状态、2D/3D/Split、Preflight、Export。
2. 左 Rail：Structure / Select / Text / Image / Shape / Line / Marks / Barcode / QR / Symbols / Layers / Dieline CAD / Assets / 3D。
3. 左 Mode Panel：根据 Rail 模式切换内容。
4. 中央 Canvas：Single Face / Multi Face / Full Dieline。
5. 右区：3D Preview 与 Inspector 可切换或并列。
6. Inspector 支持 collapse + resize。

## Phase B — Template Detail / Generator

1. Template Center 卡片化重做；
2. 搜索：自然语言 + FEFCO + ECMA + Model ID；
3. Detail 页面显示：
   - 制造尺寸；
   - 内尺寸；
   - 外尺寸；
   - Material / Flute / Thickness；
   - 2D Dieline；
   - 3D Preview；
   - Fold slider；
   - PDF/SVG/DXF；
4. 在线设计进入 Editor 并继承当前结构参数。

## Phase C — Structure Panel

- W/H/D 数值输入；
- 拖动调整；
- dimension mode；
- material；
- flute；
- thickness；
- bend radius；
- template-specific controls：R / taper / relief / notch / shoulder。

所有修改必须：

```text
Structure → Dieline → Panels → Fold → 3D
```

实时刷新。

- keyboard nudge；

- 2D→3D / 3D→2D linked selection。

## Phase H — Export

统一 Export 菜单：

- Production PDF；
- Artwork PDF；
- Dieline PDF；
- SVG；
- DXF；
- PNG/JPG；
- 3D PNG；
- GLB；
- Batch Export。

导出前自动运行 Preflight。

## Phase I — 移除审核/付费语义

前台主路径移除：

- Approver；
- Submitted/Approved 才可导出；
- production role selector；
- premium badge；
- upgrade CTA；
- watermark unlock；
- export quota。

已有 Hosted/RBAC 代码可以作为历史/可选企业模块保留，但**不再进入默认 BoxStudio 免费设计主路径**。

## V0.40 E2E

### Case 1 — Pacdora-style beginner flow

```text
Template Center
→ 150010
→ L/W/H + material
→ 2D/3D
→ Online Design
→ Text/Image
→ Marks + Barcode/QR
→ Preflight
→ Production PDF + DXF
```

### Case 2 — Packform-style professional flow

```text
Open project
→ Structure panel drag dimension
→ Multi Face
→ Inspector exact X/Y/W/H/R
→ Fold slider
→ Dieline CAD node edit
→ topology rebuild
→ Production PDF
```

- 创建项目；
- 选择模板；
- 改尺寸；
- 设计 Artwork；
- 编辑唛头；
- 生成 Barcode/QR；
- 使用 Dieline CAD；
- 3D；
- Preflight；
- 导出 PDF/SVG/DXF。

任何 `premium / role / approval / subscription / watermark` 均不得阻断上述流程。
